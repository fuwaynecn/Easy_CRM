# Easy CRM P4（公海池、领取、每日回收）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 P3 的时间线/待办基础上，交付可配置的公海池规则、客户领取/分配/释放、每日自动回收、公海列表与前端操作入口，并补齐 500 JSON 契约、机会详情页、管理员首页范围与部门一致性守护。

**Architecture:** 后端新增 `pools` 模块承载规则、领取/分配/释放、回收任务；`audit` 模块只负责写审计日志。所有负责人变更只走 `pools/service/writes.py` 与 `pools/service/recycle.py` 两条写路径，统一写 `owner_change_logs` 和 `audit_logs`。前端沿用 TanStack Query + 现有页面模式，新增 `/pool`、`/opportunities/:id`、`/admin/pool-rules` 三个页面，并在客户详情页接入分配/释放弹窗。

**Tech Stack:** Python 3.12+ / FastAPI / SQLAlchemy 2.0（同步）/ Pydantic v2 / Alembic / PostgreSQL 16 / pytest + httpx；APScheduler 3.x（P4 唯一新增后端依赖）。React 18 + TypeScript + Vite 5 + Tailwind 3.4 + TanStack Query 5（不新增前端依赖）。

**Spec:** `docs/superpowers/specs/2026-10-29-easy-crm-design.md`（§3.3、§3.5、§3.11–§3.13、§4.1、§4.3、§5、§6.1、§10）

**Handoff / 已知限制输入：** `docs/superpowers/handoffs/2026-11-01-p3-done-p4-next.md`、`docs/superpowers/plans/p3-acceptance.md` §5

## Global Constraints

以下约束对每个任务都生效，任务内不再重复。

- **时间**：数据库与 API 一律 UTC（`timestamptz`）；“今天/已逾期/自然日”按 `Asia/Shanghai`，统一走 `app/core/timeutil.py`。禁止在前端用 `slice(0,10)` 或 `toISOString()` 做业务日期判断。
- **可见性**：所有客户读路径必须从 `app/db/scope.py::customer_query(actor)` 出发；写路径必须 `get_customer` + `assert_customer_writable`（公海客户对 sales/manager 只读，admin 可写）。
- **错误契约**：所有错误响应为 `{code, message, detail}`；403 无权限、404 不存在、400 参数语义错误、409 状态冲突、422 Pydantic 校验失败。不得把 500 的异常文本回给客户端。
- **软删除**：客户、机会、待办、跟进都按 `deleted_at IS NULL` 过滤；新表不引入软删除列，除非 spec 明确要求。
- **负责人变更唯一写入口**：P4 之后 `customers.owner_id` / `customers.department_id` 只能由 `pools/service/writes.py`（claim/assign/release）和 `pools/service/recycle.py`（recycle）修改；客户 PATCH 继续禁止 owner/dept 字段。
- **日志一致性**：每次负责人变更必须在同一事务内写一条 `owner_change_logs` 和一条 `audit_logs`（`entity="customers"`、`action="transfer"`、`before_json`/`after_json` 至少含 owner_id 与 department_id）。没有日志的负责人变更是缺陷。
- **规则唯一来源**：`pool_rules` 的读取只允许 `app/modules/pools/rules.py::load_pool_rules`；首页、回收任务、领取/分配配额都读同一份。禁止在路由或组件里复制 30/50/3。
- **新依赖**：后端只新增 `apscheduler>=3.10,<4`；前端不新增依赖。
- **测试**：所有后端测试打真实 PostgreSQL（`easycrm_test`，端口 55432），不得用 SQLite 替身；同一时刻只跑一个 pytest 进程。每个后端任务必须做一次变异验证（见各任务最后一步）。
- **提交**：每个任务一个 commit；提交信息用 `feat(p4): ...` / `test(p4): ...` / `docs(p4): ...`。不要在一个 commit 里混两个任务。
- **前端验证**：没有前端单测；每个前端任务以 `npm.cmd run build`（`tsc --noEmit && vite build`）为门禁，并在验收文档记录手工检查项。
- **不做**：Excel 导入、报表/漏斗、管理员用户管理 UI、审计日志查询页、批量操作、公海池的“认领审批”。这些留给 P5 或后续。
- **Python 环境**：`backend/.venv` 已存在；所有命令在 `backend` 目录下执行。PowerShell 先设置临时目录，避免 pytest 往系统临时目录写：
  ```powershell
  $env:TEMP="E:\Wayne\Doc\CY_CRM\.tmp\w2"; $env:TMP=$env:TEMP
  ```
- **端口**：本机 8000 被禁用；后端统一 `127.0.0.1:8081`。

## P4 裁定表（已与用户确认，实施时不得再改）

| # | 口径 | 决定 | 影响 |
|---|---|---|---|
| 1 | `max_owned` 默认值 | **50**（spec 默认） | `pool_rules.max_owned` server_default 50；领取/分配都按它判 409 |
| 2 | 回收时未关闭机会的 owner | **保留原机会 owner，不清空** | 回收只清 `customers.owner_id/department_id`；下一次 claim/assign 的 `sync_opportunity_owner` 会统一改 |
| 3 | 分配是否强制配额 | **强制；超限 409** | 目标销售 `owned_count >= max_owned` 时 `ConflictError("该销售持有客户数已达上限（50）")` |
| 4 | 释放是否要填原因 | **必填，1–200 字符** | claim/assign 的 reason 可选；release 缺 reason 由 Pydantic 422，service 直调 400 |
| 5 | `last_activity_at` 维护 | **claim 重置为 now；assign/transfer 不重置；release 不重置** | 回收只看 `last_activity_at`；分配不应该把僵尸客户“洗白” |
| 6 | `owner_change_logs.operator_id` | **允许 NULL，仅系统回收写 NULL** | spec 写 NOT NULL，这是 P4 的唯一结构性偏离；时间线显示“系统”。理由：每日 02:00 回收没有人类操作者，写一个假 admin id 会污染审计 |
| 7 | 配额计数口径 | **统计目标销售名下所有未删除客户（含 lost/inactive）** | spec 说“持有客户数”，不是“活跃客户数”；避免用户用输单规避上限 |
| 8 | 主管能否分配公海客户 | **不能；公海由 admin 分配或销售自行领取** | 公海没有 `department_id`，主管的部门边界无从判定；避免跨部门抢公海 |
| 9 | 可分配目标 | **active 的 sales/manager，且必须有部门；manager 只能选本部门；admin 可选全部** | 与 `create_customer._resolve_owner` 的口径一致 |
| 10 | `owner_change_logs.action` | `claim` / `recycle` / `assign` / `transfer` / `release` | `assign` 仅用于 from_owner 为 NULL；from_owner 非空一律 `transfer` |
| 11 | `audit_logs.action` | 所有负责人变更写 **`transfer`** | spec 枚举里没有 claim/recycle；`before_json/after_json` 保留细节，不扩枚举 |
| 12 | 管理员首页范围 | **admin 的今日/逾期看全公司可见客户；manager/sales 仍只看自己名下** | 修 P3 已知限制 #8；公海提醒仍按 `owner_id IS NOT NULL` |
| 13 | 500 契约 | `{code:"internal_error", message:"服务器内部错误", detail:null}` | 新增 `Exception` 处理器；日志记录堆栈，响应不回显异常文本 |
| 14 | 每日任务时区/时间 | `Asia/Shanghai` 02:00 回收、02:10 部门一致性 | APScheduler `BackgroundScheduler`；`settings.scheduler_enabled` 控制启动；测试置 False |
| 15 | 回收并发 | PostgreSQL **事务级 advisory lock** + `FOR UPDATE SKIP LOCKED` | 多 worker 同时到点也只跑一份；拿不到锁直接返回 0 |
| 16 | 规则行缺失 | `load_pool_rules` 返回默认值，**GET 不写库**；PATCH 时 upsert id=1 | 迁移插入 id=1；只读接口无副作用 |
| 17 | 公海列表排序 | `last_activity_at ASC NULLS FIRST, id ASC` | 最久没跟进的排前面；从未跟进（NULL）最优先 |
| 18 | P3 已知限制处理 | 修 #1（500 JSON）、#7（机会详情页）、#8（admin 首页）；#2/#5/#6/#9/#10 留 P5 | 见 `p3-acceptance.md` §5 |

### Step 1: 写失败测试

创建 `backend/tests/test_pool_rules.py`：

```python
"""公海规则配置。

三条硬约束：
1. 没有行时读默认值，GET 不能顺手写库（只读接口有副作用是运维事故）；
2. 只有 id=1 一行，数据库 CHECK 兜底；
3. `recycle_notice_days < inactive_days`，否则“提前 N 天预警”会晚于回收日。
"""

import pytest
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError

from app.core.errors import ForbiddenError, InvalidValueError
from app.modules.departments.service import create_department
from app.modules.pools.models import PoolRule
from app.modules.pools.rules import (
    DEFAULT_INACTIVE_DAYS,
    DEFAULT_MAX_OWNED,
    DEFAULT_RECYCLE_NOTICE_DAYS,
    load_pool_rules,
    update_pool_rules,
)
from app.modules.pools.schemas import PoolRulesUpdate
from app.modules.users.models import ROLE_ADMIN, ROLE_SALES
from app.modules.users.service import create_user

PASSWORD = "Passw0rd!"


def _setup(db):
    east = create_department(db, "华东销售部")
    admin = create_user(
        db,
        username="admin",
        password=PASSWORD,
        display_name="管理员",
        role=ROLE_ADMIN,
        department_id=None,
    )
    sales = create_user(
        db,
        username="sales1",
        password=PASSWORD,
        display_name="销售一",
        role=ROLE_SALES,
        department_id=east.id,
    )
    return {"admin": admin, "sales": sales, "east": east}


def _auth(client, username: str) -> dict[str, str]:
    response = client.post(
        "/api/v1/auth/login",
        json={"username": username, "password": PASSWORD},
    )
    assert response.status_code == 200, response.text
    return {"Authorization": f"Bearer {response.json()['access_token']}"}


def test_load_defaults_when_row_missing(db):
    assert db.get(PoolRule, 1) is None
    rules = load_pool_rules(db)
    assert rules.inactive_days == DEFAULT_INACTIVE_DAYS == 30
    assert rules.max_owned == DEFAULT_MAX_OWNED == 50
    assert rules.recycle_notice_days == DEFAULT_RECYCLE_NOTICE_DAYS == 3
    assert rules.auto_recycle_enabled is True
    assert rules.protect_with_open_deal is True
    assert rules.protect_with_pending_followup is True
    assert rules.notice_threshold_days == 27
    # GET 不写库：默认值不是靠一次隐式 INSERT 变出来的
    assert db.get(PoolRule, 1) is None


def test_update_creates_single_row_and_keeps_unspecified_defaults(db):
    rules = update_pool_rules(db, PoolRulesUpdate(inactive_days=10))
    assert rules.inactive_days == 10
    assert rules.max_owned == 50
    assert rules.recycle_notice_days == 3
    assert rules.notice_threshold_days == 7
    row = db.get(PoolRule, 1)
    assert row is not None
    assert row.inactive_days == 10
    assert row.max_owned == 50


def test_update_merges_existing_row(db):
    update_pool_rules(db, PoolRulesUpdate(max_owned=2))
    rules = update_pool_rules(db, PoolRulesUpdate(inactive_days=12))
    assert rules.max_owned == 2
    assert rules.inactive_days == 12


def test_update_rejects_notice_not_less_than_inactive(db):
    with pytest.raises(InvalidValueError):
        update_pool_rules(
            db, PoolRulesUpdate(inactive_days=10, recycle_notice_days=10)
        )
    assert db.get(PoolRule, 1) is None


def test_update_allows_notice_zero(db):
    rules = update_pool_rules(db, PoolRulesUpdate(recycle_notice_days=0))
    assert rules.recycle_notice_days == 0
    assert rules.notice_threshold_days == 30


def test_update_rejects_explicit_null(db):
    """PATCH 显式传 null 不能变成“把 None 合并进规则”。

    schema 用 ``int | None`` 才能表达“未提供”；如果 service 不拦 ``None``，
    下一行 ``None >= int`` 会直接 500，而不是 400。
    """
    with pytest.raises(InvalidValueError):
        update_pool_rules(db, PoolRulesUpdate(inactive_days=None))
    assert db.get(PoolRule, 1) is None


def test_second_row_rejected_by_database(db):
    db.add(PoolRule(id=2))
    with pytest.raises(IntegrityError):
        db.commit()
    db.rollback()


def test_admin_can_read_and_patch_rules(client, db):
    _setup(db)
    headers = _auth(client, "admin")
```

```python
"""公海池规则的唯一读取点。

默认值是 spec §3.11 的初始值；数据库没有行时返回默认值，GET 不写库。PATCH 才
upsert id=1。这样“读规则”是纯函数式、无副作用，测试和首页都不会因为一次 GET
改变数据库状态。
"""

from dataclasses import asdict, dataclass

from sqlalchemy.orm import Session

from app.core.errors import InvalidValueError
from app.modules.pools.models import PoolRule
from app.modules.pools.schemas import PoolRulesUpdate

DEFAULT_INACTIVE_DAYS = 30
DEFAULT_MAX_OWNED = 50
DEFAULT_AUTO_RECYCLE_ENABLED = True
DEFAULT_PROTECT_WITH_OPEN_DEAL = True
DEFAULT_PROTECT_WITH_PENDING_FOLLOWUP = True
DEFAULT_RECYCLE_NOTICE_DAYS = 3

# P3 的常量名保留：已有首页测试与文档引用它们；值必须与默认值一致。
INACTIVE_DAYS = DEFAULT_INACTIVE_DAYS
RECYCLE_NOTICE_DAYS = DEFAULT_RECYCLE_NOTICE_DAYS
NOTICE_THRESHOLD_DAYS = INACTIVE_DAYS - RECYCLE_NOTICE_DAYS


@dataclass(frozen=True)
class PoolRules:
    inactive_days: int = DEFAULT_INACTIVE_DAYS
    max_owned: int = DEFAULT_MAX_OWNED
    auto_recycle_enabled: bool = DEFAULT_AUTO_RECYCLE_ENABLED
    protect_with_open_deal: bool = DEFAULT_PROTECT_WITH_OPEN_DEAL
    protect_with_pending_followup: bool = DEFAULT_PROTECT_WITH_PENDING_FOLLOWUP
    recycle_notice_days: int = DEFAULT_RECYCLE_NOTICE_DAYS

    @property
    def notice_threshold_days(self) -> int:
        """首页预警阈值：距上次跟进达到这个天数就提示“即将回收”。"""
        return self.inactive_days - self.recycle_notice_days


def _from_row(row: PoolRule) -> PoolRules:
    return PoolRules(
        inactive_days=row.inactive_days,
        max_owned=row.max_owned,
        auto_recycle_enabled=row.auto_recycle_enabled,
        protect_with_open_deal=row.protect_with_open_deal,
        protect_with_pending_followup=row.protect_with_pending_followup,
        recycle_notice_days=row.recycle_notice_days,
    )


def load_pool_rules(db: Session) -> PoolRules:
    row = db.get(PoolRule, 1)
    return _from_row(row) if row is not None else PoolRules()


def update_pool_rules(db: Session, payload: PoolRulesUpdate) -> PoolRules:
    current = load_pool_rules(db)
    changes = payload.model_dump(exclude_unset=True)
    # `int | None` 是“可省略”的类型表达；显式 null 不是合法值。放过去会在
    # 下面的 `>=` 比较里变成 TypeError -> 500。
    if any(value is None for value in changes.values()):
        raise InvalidValueError("规则字段不能为 null")
    merged = {**asdict(current), **changes}
    rules = PoolRules(**merged)
    if rules.recycle_notice_days >= rules.inactive_days:
        raise InvalidValueError("预警天数必须小于无跟进天数")
    row = db.get(PoolRule, 1)
    if row is None:
        row = PoolRule(id=1)
        db.add(row)
    for field, value in asdict(rules).items():
        setattr(row, field, value)
    db.commit()
    return rules


def as_read(rules: PoolRules):
    """延迟 import schema，避免 rules -> schemas -> 其他 schema 的循环。"""
    from app.modules.pools.schemas import PoolRuleRead

    return PoolRuleRead(**asdict(rules))
```

```python
def days_since_local(moment: datetime, now: datetime | None = None) -> int:
    """按上海自然日算“已经几天没动静”（不看时分）。

    不能 `(now - moment).days`：那是按 24 小时整除，跨日/跨时区会差一天。

    current = (now or datetime.now(UTC)).astimezone(SHANGHAI).date()
    return (current - moment.astimezone(SHANGHAI).date()).days
```

#### 3.5 `pools/service/writes.py`

```python
"""负责人变更的唯一写入口。

P4 之后 customers.owner_id / department_id 只能从这里改：
- claim：领取，重置 last_activity_at；
- assign：分配，不重置 last_activity_at；
- release：释放，不重置 last_activity_at，也不清机会 owner（裁定 2）。
每次变更同事务写 owner_change_logs + audit_logs。
"""

from datetime import UTC, datetime

from sqlalchemy import func, select
from sqlalchemy.orm import Session

from app.core.errors import (
    ConflictError,
    ForbiddenError,
    InvalidValueError,
    NotFoundError,
)
from app.modules.audit.service import write_audit_log
from app.modules.customers.models import Customer
from app.modules.customers.service import get_customer
from app.modules.opportunities.service import sync_opportunity_owner
from app.modules.pools.models import OWNER_CHANGE_ACTIONS, OwnerChangeLog
from app.modules.pools.rules import load_pool_rules
from app.modules.users.models import (
    ROLE_ADMIN,
    ROLE_MANAGER,
    ROLE_SALES,
    STATUS_ACTIVE,
    User,
)

MAX_REASON_LENGTH = 200


def record_owner_change(
    db: Session,
    *,
    customer_id: int,
    action: str,
    from_owner_id: int | None,
    to_owner_id: int | None,
    operator_id: int | None,
    reason: str | None = None,
) -> OwnerChangeLog:
    """写一条负责人变更日志，不 commit。"""
    if action not in OWNER_CHANGE_ACTIONS:
        raise InvalidValueError(f"未知负责人变更动作：{action}")
    cleaned = (reason or "").strip() or None
    if cleaned is not None and len(cleaned) > MAX_REASON_LENGTH:
        raise InvalidValueError(f"原因不能超过 {MAX_REASON_LENGTH} 个字符")
    log = OwnerChangeLog(
        customer_id=customer_id,
        action=action,
        from_owner_id=from_owner_id,
        to_owner_id=to_owner_id,
        operator_id=operator_id,
        reason=cleaned,
    )
    db.add(log)
    return log


def _lock_customer(db: Session, customer_id: int) -> Customer | None:
    """行锁 + populate_existing：拿到的是锁住之后的最新值，不是 identity map 的旧值。"""
    return db.execute(
        select(Customer)
        .where(Customer.id == customer_id, Customer.deleted_at.is_(None))
        .with_for_update()
        .execution_options(populate_existing=True)
    ).scalar_one_or_none()


def _owned_count(db: Session, user_id: int) -> int:
    """配额口径：名下所有未删除客户（含 lost/inactive，裁定 7）。"""
    return int(
        db.execute(
            select(func.count())
            .select_from(Customer)
            .where(Customer.owner_id == user_id, Customer.deleted_at.is_(None))
        ).scalar_one()
    )


def _clean_reason(reason: str | None, *, required: bool) -> str | None:
    cleaned = (reason or "").strip()
    if not cleaned:
        if required:
            raise InvalidValueError("释放原因不能为空")
        return None
    if len(cleaned) > MAX_REASON_LENGTH:
        raise InvalidValueError(f"原因不能超过 {MAX_REASON_LENGTH} 个字符")
    return cleaned


def _audit_snapshot(customer: Customer) -> dict[str, int | None]:
    return {
        "owner_id": customer.owner_id,
        "department_id": customer.department_id,
    }


def claim_customer(
    db: Session,
    actor: User,
    customer_id: int,
    *,
    now: datetime | None = None,
) -> Customer:
    """领取公海客户。

    顺序是刻意的：先 ``get_customer`` 过可见性（别的部门的已归属客户返回 403，
    不泄露“已被领取”），再锁行复查 owner。这样并发领取只有一个赢家，另一个 409。
    """
    if actor.role not in (ROLE_SALES, ROLE_MANAGER):
        raise ForbiddenError("仅销售或主管可领取客户")
    if actor.department_id is None:
        raise InvalidValueError("账号未分配部门，无法领取客户")

    get_customer(db, actor, customer_id)
    locked = _lock_customer(db, customer_id)
    if locked is None:
        raise NotFoundError("客户不存在")
    if locked.owner_id is not None:
        raise ConflictError("该客户已被他人领取")

    # 锁目标用户：同一销售并发领取两个客户时，配额判定必须串行
    db.execute(
        # 只取 id：User.department 是 joined eager load，选整行会生成
        # LEFT OUTER JOIN，PG 报 "FOR UPDATE cannot be applied to the
        # nullable side of an outer join"。
        select(User.id).where(User.id == actor.id).with_for_update()
    ).scalar_one()
    rules = load_pool_rules(db)
    if _owned_count(db, actor.id) >= rules.max_owned:
        raise ConflictError(
            f"持有客户数已达上限（{rules.max_owned}），请先释放客户"
        )

    before = _audit_snapshot(locked)
    current = now or datetime.now(UTC)
    locked.owner_id = actor.id
    locked.department_id = actor.department_id
    locked.last_activity_at = current
    sync_opportunity_owner(db, customer_id=locked.id, owner_id=actor.id)
    record_owner_change(
        db,
        customer_id=locked.id,
        action="claim",
        from_owner_id=None,
        to_owner_id=actor.id,
        operator_id=actor.id,
    )
    write_audit_log(
        db,
        entity="customers",
        entity_id=locked.id,
        action="transfer",
        before=before,
        after=_audit_snapshot(locked),
        operator_id=actor.id,
    )
    db.commit()
    return get_customer(db, actor, customer_id)
```

```python
from dataclasses import dataclass

from sqlalchemy import func, select
from sqlalchemy.orm import joinedload

from app.core.errors import ForbiddenError
from app.modules.pools.rules import load_pool_rules
from app.modules.users.models import (
    ROLE_ADMIN,
    ROLE_MANAGER,
    ROLE_SALES,
    STATUS_ACTIVE,
    User,
)


@dataclass(frozen=True)
class AssignableUser:
    id: int
    display_name: str
    department_id: int
    department_name: str
    owned_count: int
    max_owned: int

    @property
    def quota_remaining(self) -> int:
        return max(0, self.max_owned - self.owned_count)


def list_assignable_users(db: Session, actor: User) -> list[AssignableUser]:
    """主管看本部门可分配对象；管理员看全部；销售 403。

    配额计数与领取/分配共用同一口径：所有未删除客户，含 lost/inactive（裁定 7）。
    """
    if actor.role not in (ROLE_ADMIN, ROLE_MANAGER):
        raise ForbiddenError("仅主管及以上可查看可分配用户")
    rules = load_pool_rules(db)
    counts = (
        select(
            Customer.owner_id.label("owner_id"),
            func.count().label("owned_count"),
        )
        .where(Customer.owner_id.is_not(None), Customer.deleted_at.is_(None))
        .group_by(Customer.owner_id)
        .subquery()
    )
    stmt = (
        select(User, func.coalesce(counts.c.owned_count, 0))
        .outerjoin(counts, counts.c.owner_id == User.id)
        .options(joinedload(User.department))
        .where(
            User.status == STATUS_ACTIVE,
            User.role.in_((ROLE_SALES, ROLE_MANAGER)),
            User.department_id.is_not(None),
        )
    )
    if actor.role == ROLE_MANAGER:
        stmt = stmt.where(User.department_id == actor.department_id)
    stmt = stmt.order_by(User.display_name.asc(), User.id.asc())
    return [
        AssignableUser(
            id=user.id,
            display_name=user.display_name,
            department_id=user.department_id,
            department_name=user.department.name if user.department else "",
            owned_count=int(owned_count),
            max_owned=rules.max_owned,
        )
        for user, owned_count in db.execute(stmt).all()
    ]
```

```python
def assign_customer(
    db: Session,
    actor: User,
    customer_id: int,
    *,
    owner_id: int,
    reason: str | None = None,
) -> Customer:
    """分配/转移客户。

    - 主管只能动本部门客户、只能分配给本部门成员；公海客户只有管理员能分配（裁定 8）；
    - 目标必须是 active 的 sales/manager 且有部门；
    - 强制配额（裁定 3）；
    - 不重置 last_activity_at（裁定 5），但同步未关闭机会的 owner。
    """
    if actor.role not in (ROLE_ADMIN, ROLE_MANAGER):
        raise ForbiddenError("仅主管及以上可分配客户")
    customer = get_customer(db, actor, customer_id)
    if customer.owner_id is None and actor.role != ROLE_ADMIN:
        raise ForbiddenError("公海客户请由管理员分配，或由销售自行领取")
    if actor.role == ROLE_MANAGER and customer.department_id != actor.department_id:
        raise ForbiddenError("主管只能分配本部门客户")

    locked = _lock_customer(db, customer_id)
    if locked is None:
        raise NotFoundError("客户不存在")
    if (
        locked.owner_id != customer.owner_id
        or locked.department_id != customer.department_id
    ):
        raise ConflictError("客户归属已变化，请刷新后重试")

    # User.department 是 joined eager load；不关掉会生成 LEFT OUTER JOIN，
    # PostgreSQL 拒绝 FOR UPDATE on the nullable side of an outer join。
    target = db.execute(
        select(User)
        .where(User.id == owner_id)
        .options(lazyload(User.department))
        .with_for_update()
    ).scalar_one_or_none()
    if target is None:
        raise NotFoundError("目标销售不存在")
    if target.status != STATUS_ACTIVE:
        raise InvalidValueError("目标销售已停用")
    if target.role not in (ROLE_SALES, ROLE_MANAGER):
        raise InvalidValueError("只能分配给销售或主管")
    if target.department_id is None:
        raise InvalidValueError("目标销售未分配部门")
    if actor.role == ROLE_MANAGER and target.department_id != actor.department_id:
        raise ForbiddenError("主管只能分配给本部门成员")
    if target.id == locked.owner_id:
        raise ConflictError("该客户已属于该销售")

    rules = load_pool_rules(db)
    if _owned_count(db, target.id) >= rules.max_owned:
        raise ConflictError(
            f"该销售持有客户数已达上限（{rules.max_owned}），请先释放客户"
        )

    before = _audit_snapshot(locked)
    from_owner_id = locked.owner_id
    locked.owner_id = target.id
    locked.department_id = target.department_id
    sync_opportunity_owner(db, customer_id=locked.id, owner_id=target.id)
    record_owner_change(
        db,
        customer_id=locked.id,
        action="assign" if from_owner_id is None else "transfer",
        from_owner_id=from_owner_id,
        to_owner_id=target.id,
        operator_id=actor.id,
        reason=_clean_reason(reason, required=False),
    )
    write_audit_log(
        db,
        entity="customers",
        entity_id=locked.id,
        action="transfer",
        before=before,
        after=_audit_snapshot(locked),
        operator_id=actor.id,
    )
    db.commit()
    return get_customer(db, actor, customer_id)


def release_customer(
    db: Session,
    actor: User,
    customer_id: int,
    *,
    reason: str,
) -> Customer:
    """释放回公海。

    - 仅主管及以上；主管只能释放本部门客户；
    - 原因必填（裁定 4）；
    - 清 owner/department，不改 last_activity_at；
    - 未关闭机会的 owner 保留原负责人（裁定 2），下次 claim/assign 再同步。
    """
    if actor.role not in (ROLE_ADMIN, ROLE_MANAGER):
        raise ForbiddenError("仅主管及以上可释放客户")
    cleaned_reason = _clean_reason(reason, required=True)
    customer = get_customer(db, actor, customer_id)
    if customer.owner_id is None:
        raise InvalidValueError("客户已在公海")
    if actor.role == ROLE_MANAGER and customer.department_id != actor.department_id:
        raise ForbiddenError("主管只能释放本部门客户")

    locked = _lock_customer(db, customer_id)
    if locked is None:
        raise NotFoundError("客户不存在")
    if locked.owner_id != customer.owner_id:
        raise ConflictError("客户归属已变化，请刷新后重试")

    before = _audit_snapshot(locked)
    from_owner_id = locked.owner_id
    locked.owner_id = None
    locked.department_id = None
    record_owner_change(
        db,
        customer_id=locked.id,
        action="release",
        from_owner_id=from_owner_id,
        to_owner_id=None,
        operator_id=actor.id,
        reason=cleaned_reason,
    )
    write_audit_log(
        db,
        entity="customers",
        entity_id=locked.id,
        action="transfer",
        before=before,
        after=_audit_snapshot(locked),
        operator_id=actor.id,
    )
    db.commit()
    return get_customer(db, actor, customer_id)
```

#### 5.2 `pools/service/recycle.py`

```python
"""每日回收与部门一致性守护。

回收用**事务级 advisory lock**：多 worker 同时到点也只有一个执行；拿不到锁直接
返回 0，不阻塞、不报错。候选行用 `FOR UPDATE SKIP LOCKED`，正在被领取/分配的
客户会被跳过，不会和在线请求互相等锁。
"""

import logging
from datetime import UTC, datetime, timedelta

from sqlalchemy import select, text, update
from sqlalchemy.orm import Session

from app.modules.audit.service import write_audit_log
from app.modules.customers.models import Customer
from app.modules.pools.predicates import (
    open_deal_exists,
    pending_followup_exists,
)
from app.modules.pools.rules import PoolRules, load_pool_rules
from app.modules.pools.service.writes import record_owner_change
from app.modules.users.models import User

logger = logging.getLogger(__name__)

# 任意固定 key；只要全进程用同一个值即可。0x4543524D = "ECRM"
RECYCLE_LOCK_KEY = 0x4543524D


def recycle_customers(
    db: Session,
    *,
    now: datetime | None = None,
    rules: PoolRules | None = None,
) -> int:
    """把满足四条条件的客户回收进公海，返回实际回收数。"""
    current = now or datetime.now(UTC)
    effective = rules or load_pool_rules(db)
    if not effective.auto_recycle_enabled:
        return 0

    got_lock = db.execute(
        text("SELECT pg_try_advisory_xact_lock(:key)"),
        {"key": RECYCLE_LOCK_KEY},
    ).scalar()
    if not got_lock:
        # 另一个 worker 正在跑；本事务只读了规则，回滚即可
        db.rollback()
        return 0

    threshold = current - timedelta(days=effective.inactive_days)
    conditions = [
        Customer.deleted_at.is_(None),
        Customer.owner_id.is_not(None),
        Customer.status == "active",
        Customer.last_activity_at < threshold,
    ]
    if effective.protect_with_open_deal:
        conditions.append(~open_deal_exists())
    if effective.protect_with_pending_followup:
        conditions.append(~pending_followup_exists())

    customers = list(
        db.execute(
            select(Customer)
            .where(*conditions)
            .order_by(Customer.id.asc())
            .with_for_update(skip_locked=True)
        )
        .scalars()
        .all()
    )
    for customer in customers:
        before = {
            "owner_id": customer.owner_id,
            "department_id": customer.department_id,
        }
        from_owner_id = customer.owner_id
        customer.owner_id = None
        customer.department_id = None
        # 裁定 2：不碰未关闭机会的 owner；下一次 claim/assign 会同步
        record_owner_change(
            db,
            customer_id=customer.id,
            action="recycle",
            from_owner_id=from_owner_id,
            to_owner_id=None,
            operator_id=None,
            reason=f"连续 {effective.inactive_days} 天无跟进，系统自动回收",
        )
        write_audit_log(
            db,
            entity="customers",
            entity_id=customer.id,
            action="transfer",
            before=before,
            after={"owner_id": None, "department_id": None},
            operator_id=None,
        )
    db.commit()
    return len(customers)


def sync_department_consistency(db: Session) -> int:
    """修两类冗余不一致：有 owner 但部门不等于 owner 部门；公海却有部门。"""
    owner_department = (
        select(User.department_id)
        .where(User.id == Customer.owner_id)
        .scalar_subquery()
    )
    owned = db.execute(
        update(Customer)
        .where(
            Customer.owner_id.is_not(None),
            Customer.deleted_at.is_(None),
            Customer.department_id.is_distinct_from(owner_department),
        )
        .values(department_id=owner_department)
        .execution_options(synchronize_session=False)
    )
    pool = db.execute(
        update(Customer)
        .where(
            Customer.owner_id.is_(None),
            Customer.department_id.is_not(None),
            Customer.deleted_at.is_(None),
        )
        .values(department_id=None)
        .execution_options(synchronize_session=False)
    )
    total = int(owned.rowcount or 0) + int(pool.rowcount or 0)
    if total:
        logger.warning("部门一致性修复：%d 条客户的 department_id 已校正", total)
    db.commit()
    return total
```

```python
"""每日定时任务。

APScheduler 3.x BackgroundScheduler；进程内单实例。多 worker 的重复执行由
`recycle_customers` 的 advisory lock 兜底——scheduler 层不做分布式选主。
"""

import logging
from zoneinfo import ZoneInfo

from apscheduler.schedulers.background import BackgroundScheduler
from apscheduler.triggers.cron import CronTrigger

from app.core.config import settings
from app.db.session import SessionLocal
from app.modules.pools.service import recycle_customers, sync_department_consistency

logger = logging.getLogger(__name__)

_scheduler: BackgroundScheduler | None = None


def _run_recycle_job() -> None:
    with SessionLocal() as db:
        try:
            count = recycle_customers(db)
            logger.info("每日回收完成：%d 个客户", count)
        except Exception:
            db.rollback()
            logger.exception("每日回收失败")


def _run_consistency_job() -> None:
    with SessionLocal() as db:
        try:
            count = sync_department_consistency(db)
            logger.info("部门一致性检查完成：修复 %d 条", count)
        except Exception:
            db.rollback()
            logger.exception("部门一致性检查失败")


def build_scheduler() -> BackgroundScheduler:
    tz = ZoneInfo(settings.scheduler_timezone)
    scheduler = BackgroundScheduler(timezone=tz)
    scheduler.add_job(
        _run_recycle_job,
        CronTrigger(hour=2, minute=0, timezone=tz),
        id="daily_recycle",
        replace_existing=True,
        max_instances=1,
        coalesce=True,
        misfire_grace_time=3600,
    )
    scheduler.add_job(
        _run_consistency_job,
        CronTrigger(hour=2, minute=10, timezone=tz),
        id="department_consistency",
        replace_existing=True,
        max_instances=1,
        coalesce=True,
        misfire_grace_time=3600,
    )
    return scheduler


def start_scheduler() -> None:
    global _scheduler
    if _scheduler is not None:
        return
    _scheduler = build_scheduler()
    _scheduler.start()
    logger.info("定时任务已启动（时区 %s）", settings.scheduler_timezone)


def shutdown_scheduler() -> None:
    global _scheduler
    if _scheduler is not None:
        _scheduler.shutdown(wait=False)
        _scheduler = None
```

```python
def _pool_notice(
    db: Session, actor: User, *, now: datetime, rules: PoolRules
) -> tuple[list[Customer], int]:
    threshold = now - timedelta(days=rules.notice_threshold_days)
    conditions = [
        Customer.owner_id.is_not(None),
        Customer.status == "active",
        Customer.last_activity_at < threshold,
    ]
    if rules.protect_with_open_deal:
        conditions.append(~open_deal_exists())
    if rules.protect_with_pending_followup:
        conditions.append(~pending_followup_exists())

    stmt = customer_query(actor).where(*conditions)

    total = db.execute(
        select(func.count()).select_from(stmt.subquery())
    ).scalar_one()
    items = list(
        db.execute(
            stmt.options(joinedload(Customer.owner))
            .order_by(Customer.last_activity_at.asc(), Customer.id.asc())
            .limit(HOME_BLOCK_LIMIT)
        )
        .scalars()
        .all()
    )
```

```python
def summary(
    db: Session,
    actor: User,
    *,
    now: datetime | None = None,
    rules: PoolRules | None = None,
) -> HomeSummary:
    current = now or datetime.now(UTC)
    effective = rules or load_pool_rules(db)
    start, end = today_bounds(current)

    today_items, today_total = _follow_up_block(
        db, actor, start=start, end=end, overdue=False
    )
```

```typescript
import { api } from "./client";

export interface PoolListParams {

export function listPool(params: PoolListParams = {}) {
```

```tsx
 *
```

```tsx
 * 后端 PATCH 返回完整规则，前端直接用返回值回写，不自己拼。

export default function AdminPoolRulesPage() {
  const { user } = useAuth();
  const queryClient = useQueryClient();
  const rules = useQuery({ queryKey: ["pool-rules"], queryFn: getPoolRules });
  const [inactiveDays, setInactiveDays] = useState("30");
  const [noticeDays, setNoticeDays] = useState("3");
  const [maxOwned, setMaxOwned] = useState("50");
  const [autoRecycle, setAutoRecycle] = useState(true);

  const [protectFollowUp, setProtectFollowUp] = useState(true);

  const [error, setError] = useState<string | null>(null);

    if (!rules.data) return;
    setInactiveDays(String(rules.data.inactive_days));
    setNoticeDays(String(rules.data.recycle_notice_days));
    setMaxOwned(String(rules.data.max_owned));
    setAutoRecycle(rules.data.auto_recycle_enabled);
    setProtectDeal(rules.data.protect_with_open_deal);

            className="w-full rounded-md border border-slate-300 px-3 py-2 text-sm"
```

```python
    """P4 主链路：公海列表 → 领取 → 主管分配 → 主管释放 → 时间线三条 owner_change。"""

    timeline = client.get(
        f"/api/v1/customers/{pool['id']}/timeline", headers=boss

    actions = [
        item["owner_change_action"]

    release_item = timeline.json()["items"][0]
```
