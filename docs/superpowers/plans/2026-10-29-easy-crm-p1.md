# Easy CRM P1 实施计划（骨架 · 认证 · 客户 · 联系人 · 权限）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个可登录、可录入客户与联系人、并按"销售看自己 / 主管看部门 / 管理员看全部"隔离数据的 Web CRM 第一里程碑。

**Architecture:** FastAPI 同步 SQLAlchemy 2.0 单进程应用 + React SPA。后端按领域分包（auth/users/departments/customers/contacts），每个包含 models/schemas/service/router；权限通过 `app/db/scope.py` 的统一作用域条件注入所有查询，禁止路由层裸查。前端 TanStack Query 管服务端状态，access token 存内存、refresh token 走 httpOnly cookie。

**Tech Stack:** Python 3.12、FastAPI 0.115、SQLAlchemy 2.0（同步）、psycopg3、Alembic、Pydantic v2、PyJWT、pwdlib[argon2]；React 18 + TypeScript + Vite 5 + Tailwind 3.4 + React Router 6 + TanStack Query 5 + react-hook-form/zod；PostgreSQL 16（Docker）。

**Spec:** `docs/superpowers/specs/2026-10-29-easy-crm-design.md`

## Global Constraints

- 数据库与接口时间一律 UTC（`timestamptz` / ISO 8601 带偏移）；"今天""逾期"等业务判断统一用 `Asia/Shanghai` 换算后再判断。
- 金额字段 `numeric(14,2)`，币种 CNY；接口以字符串或数字传输，前端展示保留 2 位。
- 业务主表（customers、contacts）软删除用 `deleted_at`，查询默认过滤 `deleted_at IS NULL`。
- **所有读取必须经作用域条件**（`customer_scope()` 等），路由层禁止直接 `db.execute(select(Customer))`。
- 越权一律返回 403（不是 404）。
- 错误响应体统一 `{"code": str, "message": str, "detail": any}`。
- 密码用 argon2（`pwdlib`），永不存明文、永不打日志。
- access token 存前端内存，有效期 120 分钟；refresh token 走 `httpOnly; Secure; SameSite=Lax` cookie，有效期 7 天。禁止使用 localStorage 存 token。
- 测试必须跑真实 PostgreSQL（库名 `easycrm_test`），禁止用 SQLite。
- 对外文案、错误提示、界面文字用中文；代码标识符用英文 snake_case（Python）/ camelCase（TS）。
  - **例外（前端 DTO）**：`frontend/src/api/types.ts` 里镜像后端 wire 字段的类型（如 `owner_id` / `page_size` / `is_primary`）**保持 snake_case 原样**，不做 camelCase 转换。理由：加一层字段名映射等于给每个字段配一个可能写错的翻译，写错时的表现是静默 `undefined`；镜像原字段名可以让类型错误在编译期暴露。本地变量、组件名、函数名仍用 camelCase。
- 表名 snake_case 复数；所有时间字段类型 `timestamptz`。
- 前端固定 Tailwind 3.4（不用 v4，避免配置体系差异导致返工）。

### 本计划相对 spec 的两处实现级调整

1. **登录失败计数落库**（`users.failed_login_count` / `users.locked_until`），不用内存缓存。原因：生产部署为 2 个 uvicorn worker，内存缓存不共享，锁不住。
2. **SQLAlchemy 用同步引擎**。原因：并发量只有 20 人，无长连接需求；同步栈让 pytest 夹具、Alembic、后续 APScheduler 都更简单，异步在这里只增加陷阱不增加吞吐。

```python
class AppError(Exception):

    code: str = "bad_request"

    code = "forbidden"
```

```python
def create_app() -> FastAPI:
    app = FastAPI(title="Easy CRM API", version="0.1.0")
    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.cors_origins,
        allow_credentials=True,
        allow_methods=["*"],
        allow_headers=["*"],

    @app.exception_handler(AppError)

        return JSONResponse(
            status_code=exc.status_code,
            content={"code": exc.code, "message": exc.message, "detail": exc.detail},
        )

    @app.get("/health")

        return {"status": "ok"}
```

`backend/app/db/base.py`：

```python
from datetime import datetime

from sqlalchemy import DateTime, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


class Base(DeclarativeBase):
    pass


class TimestampMixin:
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now(), nullable=False
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True),
        server_default=func.now(),
        onupdate=func.now(),
        nullable=False,
    )


class SoftDeleteMixin:
    deleted_at: Mapped[datetime | None] = mapped_column(
        DateTime(timezone=True), nullable=True, default=None
    )
```

```python
from logging.config import fileConfig

from alembic import context
from sqlalchemy import engine_from_config, pool

from app.core.config import settings
from app.db.base import Base

config = context.config
config.set_main_option("sqlalchemy.url", settings.database_url)

if config.config_file_name is not None:
    fileConfig(config.config_file_name)

target_metadata = Base.metadata


def run_migrations_offline() -> None:
    context.configure(
        url=config.get_main_option("sqlalchemy.url"),
        target_metadata=target_metadata,
        literal_binds=True,
        compare_type=True,
    )
    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online() -> None:
    connectable = engine_from_config(
        config.get_section(config.config_ini_section, {}),
        prefix="sqlalchemy.",
        poolclass=pool.NullPool,
    )
    with connectable.connect() as connection:
        context.configure(
            connection=connection, target_metadata=target_metadata, compare_type=True
        )
        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()
```

`backend/app/modules/departments/service.py`：

```python
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.core.errors import ConflictError, NotFoundError
from app.modules.departments.models import Department


def list_departments(db: Session) -> list[Department]:
    stmt = select(Department).order_by(Department.id)
    return list(db.execute(stmt).scalars().all())


def create_department(db: Session, name: str) -> Department:
    cleaned = name.strip()
    existing = db.execute(
        select(Department).where(Department.name == cleaned)
    ).scalar_one_or_none()
    if existing is not None:
        raise ConflictError("部门名称已存在")
    dept = Department(name=cleaned)
    db.add(dept)
    db.commit()
    db.refresh(dept)
    return dept


def get_department(db: Session, department_id: int) -> Department:
    dept = db.get(Department, department_id)
    if dept is None:
        raise NotFoundError("部门不存在")
    return dept
```

```python
from datetime import datetime, timedelta, timezone

from sqlalchemy import select
from sqlalchemy.orm import Session

from app.core.config import settings
from app.core.errors import ConflictError, NotFoundError, UnauthorizedError
from app.core.security import hash_password, verify_password
from app.modules.users.models import ROLE_ADMIN, ROLE_MANAGER, ROLE_SALES, ROLES, User

__all__ = [
    "ROLE_ADMIN",
    "ROLE_MANAGER",
    "ROLE_SALES",
    "ROLES",
    "authenticate",
    "create_user",
    "get_user_by_username",
    "list_users",
    "reset_password",
    "set_user_status",
]


def _now() -> datetime:
    return datetime.now(timezone.utc)


def get_user_by_username(db: Session, username: str) -> User | None:
    return db.execute(
        select(User).where(User.username == username)
    ).scalar_one_or_none()


def list_users(db: Session) -> list[User]:
    return list(db.execute(select(User).order_by(User.id)).scalars().all())


def create_user(
    db: Session,
    *,
    username: str,
    password: str,
    display_name: str,
    role: str,
    department_id: int | None,
) -> User:
    if role not in ROLES:
        raise ConflictError(f"未知角色：{role}")
    if get_user_by_username(db, username) is not None:
        raise ConflictError("登录名已存在")
    user = User(
        username=username.strip(),
        password_hash=hash_password(password),
        display_name=display_name.strip(),
        role=role,
        department_id=department_id,
    )
    db.add(user)
    db.commit()
    db.refresh(user)
    return user


def authenticate(db: Session, username: str, password: str) -> User:
    user = get_user_by_username(db, username)
    if user is None:
        raise UnauthorizedError("用户名或密码错误")
    if user.status != "active":
        raise UnauthorizedError("账号已停用")

    now = _now()
    if user.locked_until is not None and user.locked_until > now:
        raise UnauthorizedError("账号已锁定，请稍后再试")

    if not verify_password(password, user.password_hash):
        user.failed_login_count += 1
        if user.failed_login_count >= settings.login_max_failures:
            user.locked_until = now + timedelta(minutes=settings.login_lock_minutes)
            user.failed_login_count = 0
        db.commit()
        raise UnauthorizedError("用户名或密码错误")

    user.failed_login_count = 0
    user.locked_until = None
    user.last_login_at = now
    db.commit()
    db.refresh(user)
    return user


def set_user_status(db: Session, user_id: int, status: str) -> User:
    user = db.get(User, user_id)
    if user is None:
        raise NotFoundError("用户不存在")
    if status not in ("active", "disabled"):
        raise ConflictError("未知状态")
    user.status = status
    db.commit()
    db.refresh(user)
    return user


def reset_password(db: Session, user_id: int, new_password: str) -> User:
    user = db.get(User, user_id)
    if user is None:
        raise NotFoundError("用户不存在")
    user.password_hash = hash_password(new_password)
    user.failed_login_count = 0
    user.locked_until = None
    db.commit()
    db.refresh(user)
    return user
```

```python
from datetime import datetime, timedelta, timezone

import jwt
from pwdlib import PasswordHash

from app.core.config import settings
from app.core.errors import UnauthorizedError

_password_hash = PasswordHash.recommended()


def hash_password(raw: str) -> str:
    return _password_hash.hash(raw)


def verify_password(raw: str, hashed: str) -> bool:
    return _password_hash.verify(raw, hashed)


def _encode(user_id: int, token_type: str, ttl: timedelta) -> str:
    now = datetime.now(timezone.utc)
    payload = {"sub": str(user_id), "type": token_type, "iat": now, "exp": now + ttl}
    return jwt.encode(payload, settings.jwt_secret, algorithm=settings.jwt_algorithm)


def create_access_token(user_id: int) -> tuple[str, int]:
    ttl = timedelta(minutes=settings.access_token_ttl_minutes)
    return _encode(user_id, "access", ttl), int(ttl.total_seconds())


def create_refresh_token(user_id: int) -> str:
    return _encode(user_id, "refresh", timedelta(days=settings.refresh_token_ttl_days))


def decode_token(token: str, expected_type: str) -> int:
    try:
        payload = jwt.decode(
            token, settings.jwt_secret, algorithms=[settings.jwt_algorithm]
        )
    except jwt.PyJWTError as exc:
        raise UnauthorizedError("登录已过期，请重新登录") from exc
    if payload.get("type") != expected_type:
        raise UnauthorizedError("令牌类型不正确")
    try:
        return int(payload["sub"])
    except (KeyError, ValueError) as exc:
        raise UnauthorizedError("令牌内容不合法") from exc
```

```python
from sqlalchemy.orm import Session

from app.core.errors import ForbiddenError, UnauthorizedError
from app.core.security import decode_token
from app.db.session import get_db
from app.modules.users.models import ROLE_ADMIN, User


def get_current_user(
    request: Request, db: Annotated[Session, Depends(get_db)]
) -> User:
    header = request.headers.get("authorization", "")
    scheme, _, token = header.partition(" ")
    if scheme.lower() != "bearer" or not token:
        raise UnauthorizedError("未登录")
    user_id = decode_token(token, "access")
    user = db.get(User, user_id)
    if user is None or user.status != "active":
        raise UnauthorizedError("账号不可用")
    return user

    if user.role != ROLE_ADMIN:
        raise ForbiddenError("需要管理员权限")
    return user


def require_manager_or_admin(user: CurrentUser) -> User:
    if user.role not in (ROLE_ADMIN, "manager"):
```

```python
REFRESH_MAX_AGE = 60 * 60 * 24 * 7


def _set_refresh_cookie(response: Response, token: str) -> None:
    response.set_cookie(
        key="refresh_token",
        value=token,
        max_age=REFRESH_MAX_AGE,
        httponly=True,
        secure=settings.cookie_secure,
        samesite="lax",
        path=REFRESH_PATH,
    )


@router.post("/login", response_model=TokenResponse)
def post_login(payload: LoginRequest, db: Annotated[Session, Depends(get_db)], response: Response):
    user, access, refresh, expires_in = login(db, payload.username, payload.password)
    _set_refresh_cookie(response, refresh)
    return TokenResponse(
        access_token=access, expires_in=expires_in, user=UserRead.model_validate(user)
    )


@router.post("/refresh", response_model=AccessTokenResponse)
def post_refresh(
    db: Annotated[Session, Depends(get_db)],
    response: Response,
    refresh_token: Annotated[str | None, Cookie()] = None,
):
    if not refresh_token:
        raise UnauthorizedError("缺少刷新令牌")
    _, access, expires_in = refresh_access(db, refresh_token)
    _set_refresh_cookie(response, refresh_token)
    return AccessTokenResponse(access_token=access, expires_in=expires_in)


@router.post("/logout", status_code=204)
def post_logout(response: Response):
    response.delete_cookie(
        key="refresh_token", path=REFRESH_PATH, httponly=True, samesite="lax"
    )


@me_router.get("/me", response_model=UserRead)

    return user
```

```python
from sqlalchemy import ColumnElement, or_, true

from app.core.errors import ForbiddenError
from app.modules.customers.models import Customer
from app.modules.users.models import ROLE_ADMIN, ROLE_MANAGER, User


def customer_scope(user: User) -> ColumnElement[bool]:
    """返回用于 WHERE 的可见性条件。所有客户查询都必须拼上它。"""
    if user.role == ROLE_ADMIN:
        return true()
    if user.role == ROLE_MANAGER:
        return or_(
            Customer.department_id == user.department_id,
            Customer.owner_id == user.id,
        )
    return Customer.owner_id == user.id


def can_write_customer(customer: Customer, user: User) -> bool:
    if user.role == ROLE_ADMIN:
        return True
    if user.role == ROLE_MANAGER:
        return (
            customer.department_id is not None
            and customer.department_id == user.department_id
        )
    return customer.owner_id is not None and customer.owner_id == user.id


def assert_customer_writable(customer: Customer, user: User) -> None:
    if not can_write_customer(customer, user):
```

```python
import re
from datetime import datetime, timezone

from sqlalchemy import Select, func, or_, select
from sqlalchemy.orm import Session

from app.core.errors import ConflictError, ForbiddenError, NotFoundError
from app.db.scope import assert_customer_writable, customer_scope
from app.modules.customers.models import (
    BUDGET_STATUSES,
    CUSTOMER_LEVELS,
    CUSTOMER_STATUSES,
    PROCUREMENT_TYPES,
    Customer,
)
from app.modules.customers.schemas import CustomerCreate, CustomerUpdate
from app.modules.users.models import ROLE_ADMIN, User

_NOISE = re.compile(r"[\s（）()【】\[\]·,，.。\-—_/\\]")
_SORTABLE = {
    "name": Customer.name,
    "created_at": Customer.created_at,
    "updated_at": Customer.updated_at,
    "last_activity_at": Customer.last_activity_at,
    "level": Customer.level,
}


def normalize_name(name: str) -> str:
    return _NOISE.sub("", name).lower()


def find_similar_customers(db: Session, name: str, limit: int = 5) -> list[Customer]:
    target = normalize_name(name)
    if not target:
        return []
    rows = db.execute(
        select(Customer).where(Customer.deleted_at.is_(None))
    ).scalars().all()
    exact: list[Customer] = []
    fuzzy: list[Customer] = []
    for row in rows:
        candidate = normalize_name(row.name)
        if candidate == target:
            exact.append(row)
        elif target in candidate or candidate in target:
            fuzzy.append(row)
    return (exact + fuzzy)[:limit]


def _validate_enums(payload: CustomerCreate | CustomerUpdate) -> None:
    if payload.level is not None and payload.level not in CUSTOMER_LEVELS:
        raise ConflictError(f"未知客户等级：{payload.level}")
    if (
        payload.procurement_type is not None
        and payload.procurement_type not in PROCUREMENT_TYPES
    ):
        raise ConflictError(f"未知采购方式：{payload.procurement_type}")
    if (
        payload.budget_status is not None
        and payload.budget_status not in BUDGET_STATUSES
    ):
        raise ConflictError(f"未知预算状态：{payload.budget_status}")
    status = getattr(payload, "status", None)
    if status is not None and status not in CUSTOMER_STATUSES:
        raise ConflictError(f"未知客户状态：{status}")


def _resolve_owner(db: Session, actor: User, requested_owner_id: int | None) -> User | None:
    if actor.role != ROLE_ADMIN:
        return actor
    if requested_owner_id is None:
        return None
    owner = db.get(User, requested_owner_id)
    if owner is None:
        raise NotFoundError("指定的负责人不存在")
    if owner.status != "active":
        raise ConflictError("指定的负责人已停用")
    return owner


def create_customer(db: Session, actor: User, payload: CustomerCreate) -> Customer:
    _validate_enums(payload)
    if not payload.force:
        similar = find_similar_customers(db, payload.name)
        if similar:
            raise ConflictError(
                "客户名称疑似重复",
                detail={"similar": [{"id": c.id, "name": c.name} for c in similar]},
            )
    owner = _resolve_owner(db, actor, payload.owner_id)
    now = datetime.now(timezone.utc)
    customer = Customer(
        name=payload.name.strip(),
        short_name=payload.short_name,
        code=payload.code,
        industry=payload.industry,
        region=payload.region,
        address=payload.address,
        website=payload.website,
        scale=payload.scale,
        level=payload.level,
        source=payload.source,
        procurement_type=payload.procurement_type,
        budget_status=payload.budget_status,
        owner_id=owner.id if owner else None,
        department_id=owner.department_id if owner else None,
        last_activity_at=now if owner else None,
        remark=payload.remark,
        created_by=actor.id,
    )
    db.add(customer)
    db.commit()
    db.refresh(customer)
    return customer


def _base_query(actor: User) -> Select:
    return (
        select(Customer)
        .where(Customer.deleted_at.is_(None))
        .where(customer_scope(actor))
    )


def list_customers(
    db: Session,
    actor: User,
    *,
    keyword: str | None = None,
    level: str | None = None,
    status: str | None = None,
    procurement_type: str | None = None,
    budget_status: str | None = None,
    owner_id: int | None = None,
    page: int = 1,
    page_size: int = 20,
    sort: str = "-created_at",
) -> tuple[list[Customer], int]:
    stmt = _base_query(actor)
    if keyword:
        like = f"%{keyword.strip()}%"
        stmt = stmt.where(
            or_(
                Customer.name.ilike(like),
                Customer.short_name.ilike(like),
                Customer.code.ilike(like),
            )
        )
    if level:
        stmt = stmt.where(Customer.level == level)
    if status:
        stmt = stmt.where(Customer.status == status)
    if procurement_type:
        stmt = stmt.where(Customer.procurement_type == procurement_type)
    if budget_status:
        stmt = stmt.where(Customer.budget_status == budget_status)
    if owner_id is not None:
        stmt = stmt.where(Customer.owner_id == owner_id)

    total = db.execute(
        select(func.count()).select_from(stmt.subquery())
    ).scalar_one()

    descending = sort.startswith("-")
    field = sort.lstrip("-")
    column = _SORTABLE.get(field)
    if column is None:
        raise ConflictError(f"不支持的排序字段：{field}")
    stmt = stmt.order_by(column.desc() if descending else column.asc(), Customer.id)
    stmt = stmt.offset((page - 1) * page_size).limit(page_size)
    return list(db.execute(stmt).scalars().all()), int(total)


def get_customer(db: Session, actor: User, customer_id: int) -> Customer:
    stmt = _base_query(actor).where(Customer.id == customer_id)
    customer = db.execute(stmt).scalar_one_or_none()
    if customer is not None:
        return customer
    existing = db.execute(
        select(Customer).where(
            Customer.id == customer_id, Customer.deleted_at.is_(None)
        )
    ).scalar_one_or_none()
    if existing is None:
        raise NotFoundError("客户不存在")
    raise ForbiddenError("无权查看该客户")


def update_customer(
    db: Session, actor: User, customer_id: int, payload: CustomerUpdate
) -> Customer:
    customer = get_customer(db, actor, customer_id)
    assert_customer_writable(customer, actor)
    _validate_enums(payload)
    data = payload.model_dump(exclude_unset=True)
    for field, value in data.items():
        setattr(customer, field, value)
    db.commit()
    db.refresh(customer)
    return customer


def delete_customer(db: Session, actor: User, customer_id: int) -> None:
    if actor.role not in (ROLE_ADMIN, "manager"):
        raise ForbiddenError("仅主管及以上可删除客户")
    customer = get_customer(db, actor, customer_id)
    assert_customer_writable(customer, actor)
    customer.deleted_at = datetime.now(timezone.utc)
    db.commit()
```

```python
    db: Annotated[Session, Depends(get_db)],
    user: CurrentUser,
```

```python
from datetime import datetime, timezone

from sqlalchemy import select, update
from sqlalchemy.orm import Session

from app.core.errors import ConflictError, NotFoundError
from app.db.scope import assert_customer_writable
from app.modules.contacts.models import DECISION_ROLES, Contact
from app.modules.contacts.schemas import ContactCreate, ContactUpdate
from app.modules.customers.service import get_customer
from app.modules.users.models import User


def _validate_decision_role(role: str | None) -> None:
    if role is not None and role not in DECISION_ROLES:
        raise ConflictError(f"未知决策角色：{role}")


def _clear_other_primaries(db: Session, customer_id: int, keep_id: int | None) -> None:
    stmt = (
        update(Contact)
        .where(
            Contact.customer_id == customer_id,
            Contact.deleted_at.is_(None),
            Contact.is_primary.is_(True),
        )
        .values(is_primary=False)
    )
    if keep_id is not None:
        stmt = stmt.where(Contact.id != keep_id)
    db.execute(stmt)


def list_contacts(db: Session, actor: User, customer_id: int) -> list[Contact]:
    get_customer(db, actor, customer_id)
    stmt = (
        select(Contact)
        .where(Contact.customer_id == customer_id, Contact.deleted_at.is_(None))
        .order_by(Contact.is_primary.desc(), Contact.id)
    )
    return list(db.execute(stmt).scalars().all())


def create_contact(
    db: Session, actor: User, customer_id: int, payload: ContactCreate
) -> Contact:
    customer = get_customer(db, actor, customer_id)
    assert_customer_writable(customer, actor)
    _validate_decision_role(payload.decision_role)
    if payload.is_primary:
        _clear_other_primaries(db, customer_id, keep_id=None)
    contact = Contact(
        customer_id=customer_id,
        name=payload.name.strip(),
        title=payload.title,
        phone=payload.phone,
        wechat=payload.wechat,
        email=payload.email,
        is_primary=payload.is_primary,
        decision_role=payload.decision_role,
        remark=payload.remark,
    )
    db.add(contact)
    db.commit()
    db.refresh(contact)
    return contact


def _get_owned_contact(db: Session, actor: User, contact_id: int) -> Contact:
    contact = db.execute(
        select(Contact).where(Contact.id == contact_id, Contact.deleted_at.is_(None))
    ).scalar_one_or_none()
    if contact is None:
        raise NotFoundError("联系人不存在")
    customer = get_customer(db, actor, contact.customer_id)
    assert_customer_writable(customer, actor)
    return contact


def update_contact(
    db: Session, actor: User, contact_id: int, payload: ContactUpdate
) -> Contact:
    contact = _get_owned_contact(db, actor, contact_id)
    data = payload.model_dump(exclude_unset=True)
    _validate_decision_role(data.get("decision_role"))
    if data.get("is_primary") is True:
        _clear_other_primaries(db, contact.customer_id, keep_id=contact.id)
    for field, value in data.items():
        setattr(contact, field, value)
    db.commit()
    db.refresh(contact)
    return contact


def delete_contact(db: Session, actor: User, contact_id: int) -> None:
    contact = _get_owned_contact(db, actor, contact_id)
    contact.deleted_at = datetime.now(timezone.utc)
    db.commit()
```

```ts
let accessToken: string | null = null;

export function setAccessToken(token: string | null): void {
  accessToken = token;
}

export function getAccessToken(): string | null {
  return accessToken;
}

export class ApiError extends Error {
  constructor(
    public status: number,
    public code: string,
    message: string,
    public detail?: unknown,
  ) {
    super(message);
  }
}

let refreshing: Promise<boolean> | null = null;

export function tryRefresh(): Promise<boolean> {
  if (!refreshing) {
    refreshing = fetch("/api/v1/auth/refresh", {
      method: "POST",
      credentials: "include",
    })
      .then(async (resp) => {
        if (!resp.ok) return false;
        const data = (await resp.json()) as { access_token: string };
        setAccessToken(data.access_token);
        return true;
      })
      .catch(() => false)
      .finally(() => {
        refreshing = null;
      });
  }
  return refreshing;
}

async function request<T>(path: string, init: RequestInit = {}): Promise<T> {
  const send = (): Promise<Response> =>
    fetch(path, {
      ...init,
      credentials: "include",
      headers: {
        ...(init.body ? { "Content-Type": "application/json" } : {}),
        ...(accessToken ? { Authorization: `Bearer ${accessToken}` } : {}),
        ...(init.headers ?? {}),
      },
    });

  let resp = await send();
  if (resp.status === 401 && accessToken) {
    const ok = await tryRefresh();
    if (ok) resp = await send();
  }
  if (resp.status === 204) return undefined as T;

  const body = await resp.json().catch(() => null);
  if (!resp.ok) {
    const err = body as { code?: string; message?: string; detail?: unknown } | null;
    throw new ApiError(
      resp.status,
      err?.code ?? "error",
      err?.message ?? "请求失败",
      err?.detail,
    );
  }
  return body as T;
}

export const api = {
  get: <T>(path: string) => request<T>(path),
  post: <T>(path: string, body?: unknown) =>
    request<T>(path, {
      method: "POST",
      body: body === undefined ? undefined : JSON.stringify(body),
    }),
  patch: <T>(path: string, body: unknown) =>
    request<T>(path, { method: "PATCH", body: JSON.stringify(body) }),
  del: (path: string) => request<void>(path, { method: "DELETE" }),
};
```

```tsx
import { createContext, useContext, useEffect, useMemo, useState } from "react";
import type { ReactNode } from "react";

import { loginRequest, logoutRequest, meRequest } from "../api/auth";
import { setAccessToken, tryRefresh } from "../api/client";
import type { User } from "../api/types";

interface AuthState {
  user: User | null;
  loading: boolean;
  login: (username: string, password: string) => Promise<void>;
  logout: () => Promise<void>;
}

const AuthContext = createContext<AuthState | null>(null);

export function AuthProvider({ children }: { children: ReactNode }) {
  const [user, setUser] = useState<User | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    let cancelled = false;
    (async () => {
      const refreshed = await tryRefresh();
      if (refreshed) {
        try {
          const me = await meRequest();
          if (!cancelled) setUser(me);
        } catch {
          if (!cancelled) setUser(null);
        }
      }
      if (!cancelled) setLoading(false);
    })();
    return () => {
      cancelled = true;
    };
  }, []);

  const value = useMemo<AuthState>(
    () => ({
      user,
      loading,
      async login(username: string, password: string) {
        const result = await loginRequest(username, password);
        setAccessToken(result.access_token);
        setUser(result.user);
      },
      async logout() {
        await logoutRequest().catch(() => undefined);
        setAccessToken(null);
        setUser(null);
      },
    }),
    [user, loading],
  );

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

export function useAuth(): AuthState {
  const ctx = useContext(AuthContext);
  if (ctx === null) throw new Error("useAuth 必须在 AuthProvider 内使用");
  return ctx;
}
```

```ts
import { api } from "./client";
import type { Contact } from "./types";

export interface ContactBody {
  name: string;
  title?: string;
  phone?: string;
  wechat?: string;
  email?: string;
  is_primary?: boolean;
  decision_role?: string;
  remark?: string;
}

export function listContacts(customerId: number) {
  return api.get<Contact[]>(`/api/v1/customers/${customerId}/contacts`);
}

export function createContact(customerId: number, body: ContactBody) {
  return api.post<Contact>(`/api/v1/customers/${customerId}/contacts`, body);
}

export function deleteContact(contactId: number) {
  return api.del(`/api/v1/contacts/${contactId}`);
}
```

```tsx
  user: "使用者",
  other: "其他",
};

  const params = useParams();
  const customerId = Number(params.id);
  const queryClient = useQueryClient();
  const [editing, setEditing] = useState(false);
  const [remark, setRemark] = useState("");
  const [address, setAddress] = useState("");
  const [showContact, setShowContact] = useState(false);
  const [contactForm, setContactForm] = useState({
    name: "",
    title: "",
    phone: "",
    email: "",
    decision_role: "",
    is_primary: false,
  });

    queryFn: () => getCustomer(customerId),

    mutationFn: () => updateCustomer(customerId, { remark, address }),

      setEditing(false);

                onClick={() => saveMutation.mutate()}
                disabled={saveMutation.isPending}
                className="rounded-md bg-brand-500 px-3 py-2 text-sm font-medium text-white hover:bg-brand-600 disabled:opacity-60"
              >
                保存
              </button>
            </div>
          </div>
        ) : (
          <dl className="grid grid-cols-2 gap-3 text-sm">
            <div>
              <dt className="text-slate-500">地址</dt>
              <dd className="mt-0.5">{customer.address ?? "—"}</dd>
            </div>
            <div>
              <dt className="text-slate-500">官网</dt>
              <dd className="mt-0.5">{customer.website ?? "—"}</dd>
            </div>
            <div>
              <dt className="text-slate-500">采购方式</dt>

            </div>
            <div>
              <dt className="text-slate-500">预算状态</dt>
              <dd className="mt-0.5">{customer.budget_status}</dd>
            </div>
            <div className="col-span-2">
              <dt className="text-slate-500">备注</dt>
              <dd className="mt-0.5 whitespace-pre-wrap">{customer.remark ?? "—"}</dd>
            </div>
          </dl>
        )}
        {error ? <p className="text-sm text-red-600">{error}</p> : null}
      </section>

      <section className="space-y-3 rounded-lg border border-slate-200 bg-white p-4">
        <div className="flex items-center justify-between">

              onChange={(e) => setContactForm({ ...contactForm, name: e.target.value })}
            />
            <div className="grid grid-cols-2 gap-3">
              <Field
                label="职位"
                value={contactForm.title}
                onChange={(e) => setContactForm({ ...contactForm, title: e.target.value })}

                label="手机"
                value={contactForm.phone}
```
