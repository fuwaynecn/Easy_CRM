# Easy CRM P5（报表 + Excel 导入）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不碰 P4 写路径的前提下，交付 §7 的六项报表（漏斗、赢单率、成交周期、销售业绩、跟进量、输单原因）与可选的竞争对手报表，以及客户 Excel 两阶段导入（模板 → 上传校验 → 确认写入），并补齐验收文档与 P6 交接。

**Architecture:** 后端新增 `reports` 与 `imports` 两个只读/批量写模块。报表以「机会负责人当前部门」为作用域，金额一律取 `stage_histories.amount_snapshot` 时点快照；导入复用客户模型的字段校验与 `normalize_name` 查重，但**不复用** `create_customer` 的 409 分支（导入是「跳过不覆盖」），写入在单个事务内完成并只写一条 `audit_logs(action="import")` 汇总。前端新增 `/reports` 与 `/import` 两个页面，沿用 TanStack Query、Tailwind，不引入图表库。

**Tech Stack:** Python 3.12+ / FastAPI / SQLAlchemy 2.0（同步）/ Pydantic v2 / Alembic / PostgreSQL 16 / pytest + httpx；P5 新增后端依赖 `openpyxl>=3.1`、`python-multipart>=0.0.9`。React 18 + TypeScript + Vite 5 + Tailwind 3.4 + TanStack Query 5（前端不新增依赖）。

**Spec:** `docs/superpowers/specs/2026-10-29-easy-crm-design.md`（§4.6、§5、§6.1、§7、§9、§10、§11、§12）

## Global Constraints

以下约束对每个任务都生效，任务内不再重复。

- **基线**：P4 必须先 fast-forward 合入 `main`，P5 从合并后的 `main` 开 `feat/p5-reports-import`；P4 未合入前不得从 `main` 开 P5。P5 分支不 push、不 merge、不碰 `main`，除非 Wayne 明确批准。
- **时间**：数据库与 API 一律 UTC（`timestamptz`）；报表区间、月份/周桶一律按 `Asia/Shanghai`，统一走 `app/core/timeutil.py::day_start` 与 `SHANGHAI`。禁止用 UTC 日切分、禁止前端 `slice(0,10)` 做业务日期判断。
- **金额**：报表金额一律读 `stage_histories.amount_snapshot`（P3 裁定）；没有 history 的历史脏数据才回落到 `opportunities.amount`。线上金额是定点字符串，后端 `Decimal`，前端 `string`，不转 `number` 做业务计算。
- **报表可见范围**：admin 全公司；manager 本部门（按机会负责人当前 `users.department_id`）；sales 仅本人。**报表不套 `customer_query`**：公海客户对所有主管可见，按客户作用域统计会让同一条公海机会在每个部门各算一次。落地见 `reports/common.py::opportunity_scope_conditions`。
- **报表终态口径**：赢单 = 当前 `stage='won'` 且 `won_at` 在区间；输单 = 当前 `stage='lost'` 且最后一条 `to_stage='lost'` 的 `changed_at` 在区间；重开过的机会不计入原期间（重开会清 `won_at`，见 `opportunities/service/stage.py`）。
- **导入权限**：仅 `admin` / `manager`；manager 的行负责人必须属于本部门；sales 一律 403。导入只新建、不更新已有客户；重名按 `normalize_name` 全库比对后**跳过不覆盖**，跳过不计入 `error_rows`。
- **导入事务**：`POST /imports/{id}/commit` 单事务全有或全无；任一行失败整体回滚。禁止改成「每 1000 行一事务」的部分提交。
- **日志**：导入只写一条 `audit_logs(entity="imports", action="import")` 汇总；本期不写 `owner_change_logs`（新建即归属，没有 `from_owner`，批量导入不应制造时间线噪声）。将来若导入更新负责人，必须走 `pools/service/writes.py::record_owner_change`。
- **错误契约**：所有错误响应为 `{code, message, detail}`；400 参数语义错误、403 无权限、404 不存在、409 冲突、422 Pydantic 校验失败；500 不回显异常文本。
- **测试**：所有后端测试打真实 PostgreSQL（`easycrm_test`，端口 55432），不得用 SQLite；**同一时刻只跑一个 pytest 进程**；每个后端任务做一次「改坏→红→改回→绿」变异验证。
- **提交**：每个任务一个 commit，信息用 `feat(p5): ...` / `test(p5): ...` / `docs(p5): ...`；不要在一个 commit 里混两个任务。
- **前端验证**：没有前端单测；前端任务以 `npm.cmd run build`（`tsc --noEmit && vite build`）为门禁，并在验收文档记录手工检查项。
- **不做**：站内信/邮件通知、APScheduler 持久化 job store、多实例选主、客户导出、联系人/机会导入、管理员用户管理 UI、审计日志查询页。这些留给 P6 或后续。
- **Python 环境**：`backend/.venv` 已存在；所有命令在 `backend` 目录下执行。PowerShell 先设置临时目录：
  ```powershell
  $env:TEMP="E:\Wayne\Doc\CY_CRM\.tmp\w2"; $env:TMP=$env:TEMP
  ```
- **端口**：本机 8000 被禁用；后端统一 `127.0.0.1:8081`，前端 `5174`（8000 被系统禁用）。

## 报表接口契约（先锁定，任务 1 一次性写进 schemas）

所有报表端点前缀 `/api/v1/reports`，全部 `GET`，全部要求登录。区间参数统一 `date_from` / `date_to`（`YYYY-MM-DD`，可都不传；只传一个 400；`date_from > date_to` 400）。默认区间 = 上海时区**本月 1 日到今天**。响应回显实际使用的 `date_from` / `date_to`。

| 端点 | 响应要点 |
|---|---|
| `GET /reports/funnel` | 无区间参数；`as_of` + 六个阶段（顺序固定 `OPPORTUNITY_STAGES`），每阶段 `count` / `amount`；空阶段补 0 |
| `GET /reports/win-rate` | `won` / `lost` / `total` / `rate`（百分数，0–100，`total=0` 时 `null`）+ `by_department` |
| `GET /reports/cycle` | `won_count` / `avg_days` + `by_owner` + `by_month`（月份 `YYYY-MM`） |
| `GET /reports/performance` | `won_count` / `total_amount` + `by_owner` + `by_month` |
| `GET /reports/activities?granularity=day\|week` | `total` + `by_owner` + `series`（补齐空桶，桶为 `YYYY-MM-DD`，周桶是周一） |
| `GET /reports/lost-reasons` | `total_count` / `total_amount` + `items`（`lost_reason_id`、名称、条数、金额） |
| `GET /reports/competitors` | `total_opportunities` + `items`（对手名、机会数、金额、赢/输、赢单率）；同一机会多个对手分别计入，金额合计可大于机会总额 |

`rate` 一律是**百分数**（`75.0` 表示 75%），不是小数；前端直接拼 `%`。`avg_days` 保留 1 位小数。

"""报表公共口径：区间、作用域、最新阶段快照、时间桶。

报表不读 `opportunities.amount` 现值：P3 已裁定报表沿用 `stage_histories.amount_snapshot`
（`docs/superpowers/plans/2026-10-31-easy-crm-p3.md` 第 89 行）。只改金额、不换阶段不会
产生 history，所以报表金额会滞后于机会现值——这是刻意的稳定口径，不是 bug。

作用域**不套** `customer_query`：公海客户对所有主管可见，按客户作用域统计会让同一条
公海机会在每个部门各算一次。这里按机会负责人当前部门归属（P5 裁定 7/8）。
"""

from dataclasses import dataclass
from datetime import UTC, date, datetime, timedelta

from sqlalchemy import ColumnElement, func, select

from app.core.errors import InvalidValueError
from app.core.timeutil import SHANGHAI, day_start
from app.modules.activities.models import Activity
from app.modules.customers.models import Customer
from app.modules.opportunities.models import Opportunity, StageHistory
from app.modules.users.models import ROLE_ADMIN, ROLE_MANAGER, User


@dataclass(frozen=True)
class Period:
    date_from: date
    date_to: date

    @property
    def start(self) -> datetime:
        """区间起点：上海时区 `date_from` 00:00（带偏移）。"""
        return day_start(self.date_from)

    @property
    def end(self) -> datetime:
        """区间终点：上海时区 `date_to` 次日 00:00，半开区间。"""
        return day_start(self.date_to + timedelta(days=1))


def resolve_period(
    date_from: date | None,
    date_to: date | None,
    *,
    now: datetime | None = None,
) -> Period:
    """解析报表区间；都不传时默认「上海时区本月 1 日到今天」。"""
    if (date_from is None) != (date_to is None):
        raise InvalidValueError("开始日期与结束日期必须同时提供")
    if date_from is None:
        today = (now or datetime.now(UTC)).astimezone(SHANGHAI).date()
        return Period(date_from=today.replace(day=1), date_to=today)
    if date_from > date_to:
        raise InvalidValueError("开始日期不能晚于结束日期")
    return Period(date_from=date_from, date_to=date_to)


def opportunity_scope_conditions(actor: User) -> list[ColumnElement[bool]]:
    """机会报表的作用域：admin 全部、manager 本部门、sales 本人。

    部门取负责人**当前** `users.department_id`；客户已软删的机会不计入。
    未知角色按本人处理（fail-closed）。
    """
    conditions: list[ColumnElement[bool]] = [
        Opportunity.deleted_at.is_(None),
        Opportunity.customer_id.in_(
            select(Customer.id).where(Customer.deleted_at.is_(None))
        ),
    ]
    if actor.role == ROLE_ADMIN:
        return conditions
    if actor.role == ROLE_MANAGER and actor.department_id is not None:
        conditions.append(
            Opportunity.owner_id.in_(
                select(User.id).where(User.department_id == actor.department_id)
            )
        )
    else:
        conditions.append(Opportunity.owner_id == actor.id)
    return conditions


def activity_scope_conditions(actor: User) -> list[ColumnElement[bool]]:
    """跟进量报表的作用域：按跟进作者当前部门，不按客户归属。

    跟进记录一旦写下，作者就是作者；客户后来转给别人，历史跟进量仍算在原作者部门。
    """
    conditions: list[ColumnElement[bool]] = [Activity.deleted_at.is_(None)]
    if actor.role == ROLE_ADMIN:
        return conditions
    if actor.role == ROLE_MANAGER and actor.department_id is not None:
        conditions.append(
            Activity.created_by.in_(
                select(User.id).where(User.department_id == actor.department_id)
            )
        )
    else:
        conditions.append(Activity.created_by == actor.id)
    return conditions


def latest_stage_subquery(*, to_stage: str | None = None):
    """每个机会最后一条阶段历史（可按目标阶段过滤）。

    过滤必须放在窗口函数**之前**：`to_stage="won"` 要取「最后一条赢单历史」，
    而不是「最后一条历史恰好是赢单」——后者在重开后会把赢单快照丢掉。

    排序用插入顺序（`id`）：`stage_histories` 只追加，`changed_at` 由
    `server_default=now()` 写入，生产路径只有 `change_stage` 插入，没有回填；
    因此写入顺序 = 业务顺序。`changed_at` 只用于报表区间过滤，不能用来决定
    “最新一行”；Tasks 2–7 都遵守这条。
    """
    stmt = select(
        StageHistory.opportunity_id,
        StageHistory.to_stage,
        StageHistory.amount_snapshot,
        StageHistory.changed_at,
        func.row_number()
        .over(
            partition_by=StageHistory.opportunity_id,
            order_by=StageHistory.id.desc(),
        )
        .label("rn"),
    )
    if to_stage is not None:
        stmt = stmt.where(StageHistory.to_stage == to_stage)
    return stmt.subquery()


def month_bucket(column):
    """按上海时区取 `YYYY-MM`；不要用 UTC 月份，月初/月末会错位。"""
    return func.to_char(func.timezone(SHANGHAI.key, column), "YYYY-MM")


def day_bucket(column):
    return func.to_char(func.timezone(SHANGHAI.key, column), "YYYY-MM-DD")


def week_bucket(column):
    """ISO 周桶，返回该周周一的 `YYYY-MM-DD`。"""
    return func.to_char(
        func.date_trunc("week", func.timezone(SHANGHAI.key, column)),
        "YYYY-MM-DD",
    )


def fill_buckets(
    buckets: dict[str, int], period: Period, granularity: str
) -> list[tuple[str, int]]:
    """把 SQL 只返回非空桶的结果补齐成连续序列，前端不用自己补 0。"""
    if granularity == "day":
        cursor = period.date_from
        step = timedelta(days=1)
    else:
        cursor = period.date_from - timedelta(days=period.date_from.weekday())
        step = timedelta(days=7)
    result: list[tuple[str, int]] = []
    while cursor <= period.date_to:
        key = cursor.isoformat()
        result.append((key, buckets.get(key, 0)))
        cursor += step
    return result

"""报表查询。

全部函数都是只读的，不 commit、不写库。金额一律取 `stage_histories.amount_snapshot`；
只有历史脏数据没有 history 时才回落到机会现值。
"""

from datetime import UTC, datetime
from decimal import Decimal

from sqlalchemy import and_, func, select
from sqlalchemy.orm import Session

from app.modules.opportunities.models import OPPORTUNITY_STAGES, Opportunity
from app.modules.reports.common import (
    latest_stage_subquery,
    opportunity_scope_conditions,
)
from app.modules.reports.schemas import FunnelReport, FunnelStageRead
from app.modules.users.models import User


def funnel(
    db: Session, actor: User, *, now: datetime | None = None
) -> FunnelReport:
    """漏斗：当前各阶段的机会数与金额合计（存量快照，不是流量转化）。"""
    latest = latest_stage_subquery()
    stage = Opportunity.stage
    amount = func.coalesce(latest.c.amount_snapshot, Opportunity.amount)
    rows = db.execute(
        select(
            stage.label("stage"),
            func.count().label("count"),
            func.coalesce(func.sum(amount), 0).label("amount"),
        )
        .select_from(Opportunity)
        .outerjoin(
            latest,
            and_(latest.c.opportunity_id == Opportunity.id, latest.c.rn == 1),
        )
        .where(*opportunity_scope_conditions(actor))
        .group_by(stage)
    ).all()
    stats = {
        row.stage: (int(row.count), Decimal(row.amount)) for row in rows
    }
    return FunnelReport(
        as_of=now or datetime.now(UTC),
        stages=[
            FunnelStageRead(
                stage=name,
                count=stats.get(name, (0, Decimal(0)))[0],
                amount=stats.get(name, (0, Decimal(0)))[1],
            )
            for name in OPPORTUNITY_STAGES
        ],
    )

from app.modules.departments.models import Department
from app.modules.reports.common import Period
from app.modules.reports.schemas import (
    DepartmentRateRead,
    WinRateReport,
)


def _rate(won: int, lost: int) -> float | None:
    total = won + lost
    return round(won / total * 100, 1) if total else None


def win_rate(db: Session, actor: User, period: Period) -> WinRateReport:
    """期间赢单率：won / (won + lost)，按机会数，不按金额。

    赢单按 `won_at` 归属；输单没有 `lost_at` 列，按最后一条 `to_stage='lost'`
    的 `changed_at` 归属。重开过的机会当前不是终态，自然不计入。
    """
    latest = latest_stage_subquery()
    won = func.count().filter(
        Opportunity.stage == "won",
        Opportunity.won_at >= period.start,
        Opportunity.won_at < period.end,
    ).label("won")
    lost = func.count().filter(
        Opportunity.stage == "lost",
        latest.c.to_stage == "lost",
        latest.c.changed_at >= period.start,
        latest.c.changed_at < period.end,
    ).label("lost")
    rows = db.execute(
        select(User.department_id, Department.name, won, lost)
        .select_from(Opportunity)
        .join(User, User.id == Opportunity.owner_id)
        .outerjoin(Department, Department.id == User.department_id)
        .outerjoin(
            latest,
            and_(latest.c.opportunity_id == Opportunity.id, latest.c.rn == 1),
        )
        .where(
            *opportunity_scope_conditions(actor),
            Opportunity.stage.in_(("won", "lost")),
        )
        .group_by(User.department_id, Department.name)
    ).all()
    by_department = [
        DepartmentRateRead(
            department_id=row.department_id,
            department_name=row.name or "未分配",
            won=int(row.won),
            lost=int(row.lost),
            total=int(row.won) + int(row.lost),
            rate=_rate(int(row.won), int(row.lost)),
        )
        for row in rows
        if int(row.won) + int(row.lost) > 0
    ]
    by_department.sort(key=lambda row: (row.department_id is None, row.department_name))
    total_won = sum(row.won for row in by_department)
    total_lost = sum(row.lost for row in by_department)
    return WinRateReport(
        date_from=period.date_from,
        date_to=period.date_to,
        won=total_won,
        lost=total_lost,
        total=total_won + total_lost,
        rate=_rate(total_won, total_lost),
        by_department=by_department,
    )

    return round(float(value), 1) if value is not None else None


def cycle(db: Session, actor: User, period: Period) -> CycleReport:
    """平均成交周期：当前赢单机会的 `won_at - created_at` 天数均值。

    期间按 `won_at` 归属；重开过的机会 `won_at` 被清空，不再计入。
    """
    days = func.extract(
        "epoch", Opportunity.won_at - Opportunity.created_at
    ) / 86400.0
    base = [
        *opportunity_scope_conditions(actor),
        Opportunity.stage == "won",
        Opportunity.won_at >= period.start,
        Opportunity.won_at < period.end,
    ]
    won_count, avg_days = db.execute(
        select(func.count(), func.avg(days)).where(*base)
    ).one()
    month = month_bucket(Opportunity.won_at)
    owner_rows = db.execute(
        select(User.id, User.display_name, func.count(), func.avg(days))
        .join(User, User.id == Opportunity.owner_id)
        .where(*base)
        .group_by(User.id, User.display_name)
        .order_by(User.display_name.asc(), User.id.asc())
    ).all()
    month_rows = db.execute(
        select(month.label("month"), func.count(), func.avg(days))
        .where(*base)
        .group_by(month)
        .order_by(month.asc())
    ).all()
    return CycleReport(
        date_from=period.date_from,
        date_to=period.date_to,
        won_count=int(won_count),
        avg_days=_avg_days(avg_days),
        by_owner=[
            CycleOwnerRead(
                owner_id=row.id,
                owner_name=row.display_name,
                won_count=int(row[2]),
                avg_days=_avg_days(row[3]),

            for row in owner_rows
        ],
        by_month=[
            CycleMonthRead(

from app.modules.lost_reasons.models import LostReason
from app.modules.reports.schemas import LostReasonRead, LostReasonReport


def lost_reasons(
    db: Session, actor: User, period: Period
) -> LostReasonReport:
    """输单原因：期间内按原因分组的机会数与金额。

    输单时间没有独立列，取最后一条 `to_stage='lost'` 的 `changed_at`；
    金额取同一条历史的快照。
    """
    lost_hist = latest_stage_subquery(to_stage="lost")
    amount = func.coalesce(lost_hist.c.amount_snapshot, Opportunity.amount)
    rows = db.execute(
        select(
            LostReason.id,
            LostReason.name,
            func.count().label("count"),
            func.coalesce(func.sum(amount), 0).label("amount"),
        )
        .select_from(Opportunity)
        .join(
            lost_hist,
            and_(lost_hist.c.opportunity_id == Opportunity.id, lost_hist.c.rn == 1),
        )
        .join(LostReason, LostReason.id == Opportunity.lost_reason_id)
        .where(
            *opportunity_scope_conditions(actor),
            Opportunity.stage == "lost",
            lost_hist.c.changed_at >= period.start,
            lost_hist.c.changed_at < period.end,
        )
        .group_by(LostReason.id, LostReason.name)
        .order_by(func.count().desc(), func.sum(amount).desc(), LostReason.id.asc())
    ).all()
    items = [
        LostReasonRead(
            lost_reason_id=row.id,
            lost_reason_name=row.name,
            count=int(row.count),
            amount=Decimal(row.amount),
        )
        for row in rows
    ]
    return LostReasonReport(
        date_from=period.date_from,
        date_to=period.date_to,
        total_count=sum(item.count for item in items),
        total_amount=sum((item.amount for item in items), Decimal(0)),
        items=items,
    )

```python
from app.modules.reports.schemas import CompetitorRead, CompetitorReport


def competitors(
    db: Session, actor: User, period: Period
) -> CompetitorReport:
    """竞争对手：期间**新建**机会按 `competitor` 文本拆分。

    拆分只按 spec 写的顿号「、」；同一机会里重复的对手去重。一个机会多个对手时
    分别计入，因此条数与金额合计都可能大于机会总数——这是口径，不是重复计算 bug。
    """
    latest = latest_stage_subquery()
    amount = func.coalesce(latest.c.amount_snapshot, Opportunity.amount)
    rows = db.execute(
        select(
            Opportunity.id,
            Opportunity.competitor,
            Opportunity.stage,
            amount.label("amount"),
        )
        .select_from(Opportunity)
        .outerjoin(
            latest,
            and_(latest.c.opportunity_id == Opportunity.id, latest.c.rn == 1),
        )
        .where(
            *opportunity_scope_conditions(actor),
            Opportunity.competitor.is_not(None),
            Opportunity.created_at >= period.start,
            Opportunity.created_at < period.end,
        )
    ).all()
    stats: dict[str, dict] = {}
    opportunities = 0
    for row in rows:
        names = {part.strip() for part in row.competitor.split("、") if part.strip()}
        if not names:
            continue
        opportunities += 1
        for name in names:
            item = stats.setdefault(
                name,
                {"count": 0, "amount": Decimal(0), "won": 0, "lost": 0},
            )
            item["count"] += 1
            item["amount"] += Decimal(row.amount)
            if row.stage == "won":
                item["won"] += 1
            elif row.stage == "lost":
                item["lost"] += 1
    items = [
        CompetitorRead(
            competitor=name,
            count=item["count"],
            amount=item["amount"],
            won=item["won"],
            lost=item["lost"],
            rate=_rate(item["won"], item["lost"]),
        )
        for name, item in stats.items()
    ]
    items.sort(key=lambda row: (-row.count, row.competitor))
    return CompetitorReport(
        date_from=period.date_from,
        date_to=period.date_to,
        total_opportunities=opportunities,
        items=items,
    )

function FunnelBars({ data }: { data: { stages: { stage: string; count: number; amount: string }[] } }) {

          </div>
          <div className="h-2 rounded bg-slate-100">
            <div className="h-2 rounded bg-brand-500" style={{ width: `${Math.min(100, (Number(row.amount) / max) * 100)}%` }} />
          </div>
        </div>
      ))}
    </div>
  );
}

function SeriesBars({ series }: { series: { bucket: string; count: number }[] }) {

        </div>
      ))}
    </div>
  );
}

from datetime import datetime
from typing import Any

from pydantic import BaseModel, ConfigDict, model_validator


class ImportErrorRead(BaseModel):
    row: int
    column: str
    message: str


class ImportJobRead(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    kind: str
    file_name: str | None
    status: str
    total_rows: int
    success_rows: int
    skipped_rows: int
    error_rows: int
    errors: list[ImportErrorRead] = []
    created_at: datetime

    @model_validator(mode="before")
    @classmethod
    def _errors_from_json(cls, data: Any) -> Any:
        """ORM 上是 `errors_json`，wire 上是 `errors`；不要在响应里暴露 JSONB 列名。"""
        if isinstance(data, (dict, cls)):
            return data
        values = {
            field: getattr(data, field)
            for field in cls.model_fields
            if field != "errors"
        }
        values["errors"] = getattr(data, "errors_json", None) or []
        return values

@dataclass(frozen=True)
class ParsedCustomerRow:
    row: int

    owner_username: str

@dataclass

def _text(value: Any) -> str:
    if value is None:
        return ""
    if isinstance(value, float) and value.is_integer():
        return str(int(value))
    return str(value).strip()


def _enum(
    value: str,
    mapping: dict[str, str],
    *,
    row: int,
    column: str,
    default: str | None,
    errors: list[ImportErrorRead],
) -> str | None:
    if not value:
        return default
    resolved = mapping.get(value)
    if resolved is None:
        errors.append(
            ImportErrorRead(
                row=row, column=column, message=f"不支持的值：{value}"
            )
        )
        return default
    return resolved


def parse_customer_workbook(content: bytes) -> ParseResult:
    """解析客户 xlsx；只返回结构合法的行，行级错误单独收集。"""
    try:
        workbook = load_workbook(BytesIO(content), read_only=True, data_only=True)
    except Exception as exc:  # noqa: BLE001 - 第三方库异常类型不稳定，统一转 400
        raise InvalidValueError("无法读取 Excel 文件，请确认是 .xlsx 格式") from exc

    sheet = workbook.active
    if sheet is None:
        workbook.close()
        raise InvalidValueError("Excel 文件没有工作表")

    rows_iter = sheet.iter_rows(values_only=True)
    try:
        header_values = next(rows_iter)
    except StopIteration as exc:
        workbook.close()
        raise InvalidValueError("Excel 文件是空的") from exc

    headers = [_text(value) for value in header_values]
    missing = [name for name in ("客户名称*", "负责人*") if name not in headers]
    if missing:
        workbook.close()
        return ParseResult(
            rows=[],
            errors=[
                ImportErrorRead(
                    row=1, column="表头", message="缺少列：" + "、".join(missing)
                )
            ],
            total_rows=0,
        )

    positions = {
        name: index for index, name in enumerate(headers) if name
    }
    parsed: list[ParsedCustomerRow] = []
    errors: list[ImportErrorRead] = []
    total_rows = 0
    for row_number, values in enumerate(rows_iter, start=2):
        cells = [_text(value) for value in values]
        if not any(cells):
            continue
        total_rows += 1
        if total_rows > MAX_IMPORT_ROWS:
            errors.append(
                ImportErrorRead(
                    row=row_number,
                    column="",
                    message=f"单次最多导入 {MAX_IMPORT_ROWS} 行",
                )
            )
            break

        def cell(header: str) -> str:
            position = positions.get(header)
            return cells[position] if position is not None and position < len(cells) else ""

        name = cell("客户名称*")
        owner = cell("负责人*")
        row_errors_before = len(errors)
        if not name:
            errors.append(
                ImportErrorRead(row=row_number, column="客户名称*", message="必填")
            )
        elif len(name) > 200:
            errors.append(
                ImportErrorRead(
                    row=row_number, column="客户名称*", message="不能超过 200 字"
                )
            )
        if not owner:
            errors.append(
                ImportErrorRead(row=row_number, column="负责人*", message="必填")
            )
        elif len(owner) > 64:
            errors.append(
                ImportErrorRead(
                    row=row_number, column="负责人*", message="不能超过 64 字"
                )
            )

        fields: dict[str, str | None] = {}
        for header, field in (
            ("简称", "short_name"),
            ("编码", "code"),
            ("行业", "industry"),
            ("地区", "region"),
            ("地址", "address"),
            ("网站", "website"),
            ("规模", "scale"),
            ("来源", "source"),
            ("备注", "remark"),
        ):
            value = cell(header) or None
            limit = _FIELD_LIMITS.get(field)
            if value is not None and limit is not None and len(value) > limit:
                errors.append(
                    ImportErrorRead(
                        row=row_number, column=header, message=f"不能超过 {limit} 字"
                    )
                )
            fields[field] = value

        fields["level"] = _enum(
            cell("等级"), _LEVELS, row=row_number, column="等级",
            default="C", errors=errors,
        )
        fields["procurement_type"] = _enum(
            cell("采购方式"), _PROCUREMENT, row=row_number, column="采购方式",
            default=None, errors=errors,
        )
        fields["budget_status"] = _enum(
            cell("预算状态"), _BUDGET, row=row_number, column="预算状态",
            default="unknown", errors=errors,
        )
        fields["status"] = _enum(
            cell("客户状态"), _STATUS, row=row_number, column="客户状态",
            default="active", errors=errors,
        )
        if len(errors) > row_errors_before:
            continue
        parsed.append(
            ParsedCustomerRow(
                row=row_number,
                name=name,
                owner_username=owner,
                fields=fields,
            )
        )
    workbook.close()
    return ParseResult(rows=parsed, errors=errors, total_rows=total_rows)


def validate_customer_rows(
    db: Session, actor: User, rows: list[ParsedCustomerRow]
) -> ValidationResult:
    """按负责人与全库重名做业务校验；重名进 `skipped`，不是错误。"""
    users = db.execute(
        select(User).where(User.status == STATUS_ACTIVE)
    ).scalars().all()
    by_username = {user.username: user for user in users}
    existing = {
        normalize_name(name)
        for (name,) in db.execute(
            select(Customer.name).where(Customer.deleted_at.is_(None))
        ).all()
    }
    errors: list[ImportErrorRead] = []
    valid: list[ParsedCustomerRow] = []
    skipped: list[ParsedCustomerRow] = []
    seen_in_file: set[str] = set()
    for row in rows:
        owner = by_username.get(row.owner_username)
        if owner is None:
            errors.append(
                ImportErrorRead(
                    row=row.row,
                    column="负责人*",
                    message=f"找不到启用的用户：{row.owner_username}",
                )
            )
            continue
        if actor.role == ROLE_MANAGER and owner.department_id != actor.department_id:
            errors.append(
                ImportErrorRead(
                    row=row.row,
                    column="负责人*",
                    message="只能导入本部门负责人",
                )
            )
            continue
        if owner.department_id is None:
            errors.append(
                ImportErrorRead(
                    row=row.row,
                    column="负责人*",
                    message="负责人未分配部门，无法导入",
                )
            )
            continue
        key = normalize_name(row.name)
        if not key:
            errors.append(
                ImportErrorRead(
                    row=row.row, column="客户名称*", message="名称规范化后为空"
                )
            )
            continue
        if key in existing or key in seen_in_file:
            skipped.append(row)
            continue
        seen_in_file.add(key)
        valid.append(row)
    return ValidationResult(valid=valid, errors=errors, skipped=skipped)


def _job_path(job_id: int) -> Path:
    return Path(settings.import_dir) / f"{job_id}.xlsx"


def create_import_job(
    db: Session, actor: User, file_name: str, content: bytes
) -> ImportJob:
    """上传阶段：解析 + 校验 + 落文件；不写客户。"""
    if not content:
        raise InvalidValueError("文件是空的")
    if len(content) > MAX_IMPORT_BYTES:
        raise InvalidValueError("文件不能超过 5MB")

    job = ImportJob(
        kind="customers",
        file_name=Path(file_name).name[:255] or None,
        status="validating",
        created_by=actor.id,
    )
    db.add(job)
    db.flush()

    parsed = parse_customer_workbook(content)
    result = validate_customer_rows(db, actor, parsed.rows)
    errors = [*parsed.errors, *result.errors]

    path = _job_path(job.id)
    try:
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_bytes(content)
    except OSError as exc:
        db.rollback()
        raise InvalidValueError("导入文件保存失败，请重试") from exc

    job.total_rows = parsed.total_rows
    job.success_rows = 0
    job.skipped_rows = len(result.skipped)
    # error_rows 是“出错的行数”，不是错误条数：一行可能同时缺名称和负责人
    job.error_rows = len({error.row for error in errors})
    job.errors_json = [error.model_dump() for error in errors] or None
    job.status = "validated" if not errors else "failed"
    db.commit()
    db.refresh(job)
    return job


def get_import_job(db: Session, actor: User, job_id: int) -> ImportJob:
    """任务可见性：admin 全部，manager 仅自己创建的；越权按 404 处理。"""
    job = db.get(ImportJob, job_id)
    if job is None:
        raise NotFoundError("导入任务不存在")
    if actor.role != ROLE_ADMIN and job.created_by != actor.id:
        raise NotFoundError("导入任务不存在")
    return job

def commit_import_job(
    db: Session, actor: User, job_id: int
) -> ImportJob:
    """确认写入：重新解析校验，单事务建客户，失败整体回滚。"""
    job = get_import_job(db, actor, job_id)
    if job.status == "done":
        raise InvalidValueError("该导入任务已完成")
    if job.status != "validated":
        raise InvalidValueError("校验未通过，请修正后重新上传")

    path = _job_path(job.id)
    if not path.exists():
        job.status = "failed"
        job.error_rows = 1
        job.errors_json = [
            {"row": 0, "column": "", "message": "导入文件已丢失，请重新上传"}
        ]
        db.commit()
        raise InvalidValueError("导入文件已丢失，请重新上传")

    parsed = parse_customer_workbook(path.read_bytes())
    result = validate_customer_rows(db, actor, parsed.rows)
    errors = [*parsed.errors, *result.errors]
    job.total_rows = parsed.total_rows
    job.skipped_rows = len(result.skipped)
    job.error_rows = len({error.row for error in errors})

    if errors:
        job.status = "failed"
        job.errors_json = [error.model_dump() for error in errors]
        db.commit()
        raise InvalidValueError("校验未通过，未写入任何客户")

    try:
        for row in result.valid:
            owner = db.execute(
                select(User).where(User.username == row.owner_username)
            ).scalar_one()
            db.add(
                Customer(
                    name=row.name,
                    owner_id=owner.id,
                    department_id=owner.department_id,
                    created_by=actor.id,
                    last_activity_at=None,
                    **row.fields,
                )
            )
        job.status = "done"
        job.success_rows = len(result.valid)
        job.error_rows = 0
        job.errors_json = None
        write_audit_log(
            db,
            entity="imports",
            entity_id=job.id,
            action="import",
            before=None,
            after={
                "kind": job.kind,
                "file_name": job.file_name,
                "total_rows": job.total_rows,
                "success_rows": job.success_rows,
                "skipped_rows": job.skipped_rows,
            },
            operator_id=actor.id,
        )
        db.commit()
    except Exception:
        db.rollback()
        # 回滚后 job 的状态也回到 validated；用一条独立事务记失败，避免“明明失败却显示可重试”
        job = db.get(ImportJob, job_id)
        if job is not None:
            job.status = "failed"
            job.error_rows = 1
            job.errors_json = [
                {"row": 0, "column": "", "message": "写入失败，已整体回滚"}
            ]
            db.commit()
        raise
    db.refresh(job)
    return job
```

async function requestBlob(path: string): Promise<Blob> {
  const send = (): Promise<Response> =>
    fetch(path, {
      credentials: "include",
      headers: accessToken ? { Authorization: `Bearer ${accessToken}` } : {},
    });

  let resp = await send();
  if (resp.status === 401 && accessToken) {
    const ok = await tryRefresh();
    if (ok) resp = await send();
  }
  if (!resp.ok) {
    const body = await resp.json().catch(() => null);
    const err = body as { code?: unknown; message?: unknown; detail?: unknown } | null;
    const rawMessage = err?.message;
    const code = typeof err?.code === "string" && err.code !== "" ? err.code : "error";
    const message =
      typeof rawMessage === "string" && rawMessage.trim() !== ""
        ? rawMessage
        : fallbackMessage(resp.status);
    throw new ApiError(resp.status, code, message, err?.detail);
  }
  return resp.blob();
}
