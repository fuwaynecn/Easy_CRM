## 3. 已知限制（P4 要接的坑，逐条对应 `p3-acceptance.md` §5）

1. 时间线内**没有可点跳转**：P3 无机会详情路由、联系人无单条页；已删对象更不给。
2. 主管在时间线上**没有**编辑/删除入口（后端允许，前端保守，避免复算部门规则）。
3. 时间线**不含** `owner_change`（P4 建表后接入，前端渲染分支已预留）。
4. 首页「即将进公海」判定按**瞬时 27×24h**、展示按**上海自然日**，边界上会「显示 27 天但未进预警」。
5. 「今天已过点」的待办仍算今日待办（spec §4.5 的逾期定义是 `due_at < 今天 0 点`），前端自行标红。
6. 金额 `0.00` 表示当时未填（`amount_snapshot` 的歧义，P5 报表同样要处理）。
7. 未捕获异常返回**纯文本** `Internal Server Error`，与 `{code,message,detail}` 不一致。
8. `admin` 的首页也是"我名下客户"（裁定 3 字面），admin 首页恒为空。
9. `.superpowers/sdd/**` 不入库：ledger/report/review 只在本地。
10. e2e 只覆盖 HTTP 层，浏览器渲染全靠手工清单（前端无测试框架，spec §10）。

## 4. P4 开场必读（按影响面排序）

### 4.1 `owner_change_logs`（补全时间线第三类来源）

- 表结构见 spec §3.12：`customer_id`、`action`（`claim`/`recycle`/`assign`/`transfer`/`release`）、
  `from_owner_id`/`to_owner_id`、`created_by`、`created_at`。
- 接入点只有两处：`timeline/service.py` 的合并查询（加一路）与 **`CURSOR_TYPES`（把 `owner_change` 加进去）**。
  **现在游标层显式拒绝该类型**（`test_timeline.py::test_timeline_cursor_rejects_unimplemented_owner_change_type`），
  加表时这条测试要一起改，否则线上旧游标与新游标会互相打架。
- 前端 `Timeline.tsx` 已有 `owner_change` 分支（当前渲染「负责人变更」），契约不用改。

### 4.2 公海规则可配置（`pool_rules` 单行表）

- 现在常量在 `app/modules/pools/rules.py`：`INACTIVE_DAYS=30`、`RECYCLE_NOTICE_DAYS=3`，阈值 27 天。
- P4 要换成读 `pool_rules` 单行配置（spec §3.11），注意**判定瞬时、展示自然日**这层拆分不能合并
  （见 §3 #4），否则首页文案会跟着规则改动一起漂。
- 每日回收任务（spec §4.1）当前**不存在**，P4 建 `APScheduler` 时要先取 advisory lock，
  并按四个条件同时判定（含两条豁免，逻辑已在 `home/service.py` 写过一遍，**复用它、别写第二套**）。

### 4.3 机会详情路由

- P2/P3 都没有 `/opportunities/{id}` 页面。P4 若加：`Timeline.tsx` 里机会名可以从纯文本换成 `Link`
  （`opportunity_deleted` 为真时仍不链接），这是 §3 #1 的收口点。

### 4.4 未捕获异常的 JSON 契约

- 500 现在返回 Starlette 默认纯文本 `Internal Server Error`。P4 要加 `Exception` 兜底处理器，
  输出 `{code:"internal_error", message:"服务器内部错误", detail:null}`，并注意**不要把堆栈写进响应**。
- 顺带需要一条测试：造一个会抛非 HTTPException 的路由（或 monkeypatch 服务层）→ 断言 500 的 body 是 JSON。

### 4.5 `CustomerListPage` 的时区 bug 已在 P3 修掉

- T9 收尾把「最后跟进」从 `getMonth()/getDate()`（浏览器本地时区）改成
  `formatDay(value).slice(5)`（上海日期）。**P1/P2 的验收文档里如果写着"用本地时区显示月日"，
  以这条为准**——那是个 bug，不是特性。
- 同类问题在 `constants/datetime.ts` 有防线：`toLocaleDateString` / `toISOString().slice` 一律禁止，
  `clockFormatter` **只写 `hourCycle:"h23"`**（同时写 `hour12:false` 会让 `hourCycle` 被 V8 忽略）。
